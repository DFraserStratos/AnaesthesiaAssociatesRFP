# Changes

This folder holds one change log per requirements update, named `YYYY-MM-DD-requirements-update.md`
after the date of the input. Each log records what the update did to the catalogue in
`../`: the inputs, the questions answered, the items changed, added, retired or moved, the
new questions, the `domain-model.md` changes, the points that changed nothing, and what is left for
Donald to decide. The build-plan update (`/update-build-plan`) reads these logs to see what changed
in the requirements.
