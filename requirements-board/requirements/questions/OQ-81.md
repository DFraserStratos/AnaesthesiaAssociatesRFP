## Answer

Short-notice sickness takes the same path as any other unavailability on a booked Slot (OQ-64), never a conflict with the Bookings left in place. An anaesthetist can never keep a List on a Slot they have marked unavailable. When they mark a Slot unavailable and it holds a List, the system detects it and makes them choose there and then: transfer the List to another anaesthetist, or return it to the office as a Draft List. A returned List shows among the office's Draft Lists, nearest day first, so it does not disappear. The exact screens are still to be designed.

Ben's practice, relayed by Greg: on the day (and always after hours) the anaesthetist usually finds a colleague themselves, often one doing a morning List at the same hospital; for the next day or later they hand it to the office.

Donald: "I don't see that there should ever be a state where you keep it with yourself and mark yourself as unavailable, because then it requires proactive searching from the admin team." Greg: "It forces them to make that decision about do you want to transfer this list or do you want to return it to the office? So that's conscious."
