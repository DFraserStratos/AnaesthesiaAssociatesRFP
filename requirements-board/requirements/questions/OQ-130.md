The [invoice description](US-08.4.6) is a series of defaults: the rooms' description, replaced by the hospital's when it arrives, replaced by the chosen Contract's invoice description where it has one. AA admins can edit it at any time, as free text. Nothing on record says what happens when a default arrives after an admin has edited it.

1. **Does the hospital's description, arriving late, replace an admin's edit?** For example, the office edits the rooms' text at booking setup, then the hospital's list arrives.
2. **Does choosing a Contract, or changing it, replace an admin's edit?**

Recommendation: an admin's edit is kept, and a later default never replaces it. The office sees that a newer received description has arrived, so it can choose to use it.

Reworded 5 November to the flat Contract model: "Contract line" is now "Contract", since there are no Contract lines.

## Answer

Answered 5 November (Donald, for the build; not yet confirmed by AA or Greg). Donald: "the Procedure's invoice description always wins over the hospital's description on the invoice." The default chain stays as it was (the rooms' text, replaced by the hospital's, replaced by the chosen Contract's invoice description where it has one). That an admin's edit always wins over all of them is the proposal's reading (AR-58 section 11.2), which Donald confirmed as his ruling on 5 November when this answer was checked. So:

1. The hospital's description, arriving late, does not replace an admin's edit, nor a Contract's invoice description. This follows from Donald's words.
2. Choosing or changing a Contract does not replace an admin's edit. Donald's ruling (5 November), not yet confirmed by AA or Greg.

This matches the recommendation's first sentence. Whether the office is shown that a newer received description has arrived was not said.

The meeting of the same day changes the text on the Booking, not this answer. Ben asked for the hospital's procedure text to replace the rooms' text, "just accept the hospital's version", with the original kept in the history (Donald: "you'd always be able to see what the original one was in the history"). Whether a late hospital text replaces an admin's edit was not raised in the meeting.
