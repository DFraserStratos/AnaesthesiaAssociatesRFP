The [invoice description](US-08.4.6) is a series of defaults: the rooms' description, replaced by the hospital's when it arrives, replaced by the chosen Contract line's invoice description where it has one. AA admins can edit it at any time, as free text. Nothing on record says what happens when a default arrives after an admin has edited it.

1. **Does the hospital's description, arriving late, replace an admin's edit?** For example, the office edits the rooms' text at booking setup, then the hospital's list arrives.
2. **Does choosing a Contract line, or changing it, replace an admin's edit?**

Recommendation: an admin's edit is kept, and a later default never replaces it. The office sees that a newer received description has arrived, so it can choose to use it.
