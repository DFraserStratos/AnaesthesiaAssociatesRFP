The invoice prints its own wording for each Procedure, never the source text ([source wording](US-03.1.9)). Which description does it print? The current position is the 16 October update below.

History, superseded on 16 October: on 8 October every RVG group had a general procedure, taken by a Procedure reached from the RVG codes tab and priced on No contract (RVG), and the question was what that general procedure's name should say on the invoice. The recommendation to name each general procedure by section, tier and code, and to flag such Procedures at office review, is withdrawn: the procedure master and its general procedures fall away (OQ-88).

Update 2026-10-16: the question becomes which description the invoice prints. Donald left it open: "anything that says RVG, I'm nervous because... it's all gonna change a little bit."

- Agreed in principle: the Booking keeps the surgeon's rooms' description and the hospital's description, and adds an invoice description, "a copy of the booking procedure description, or the contract line description if there is one". Ben prefers the Contract line's description where one applies. See Notes 2026-10-16 · AA meeting with Greg #36 #38; Notes 2026-10-16 · Pricing model documents v6 #8 #29.
- Open: what the invoice says when only an RVG code was picked (No contract (RVG), or a hospital's plain RVG Contract): "if I'm a patient, do I want to receive an H1 minor procedures...?" Greg: "No, I agree." Greg leaves it to the developers. See Notes 2026-10-16 · AA meeting with Greg #37.
- Donald's idea: when invoicing a hospital, use the hospital's own description; Greg: "that makes sense". The anaesthetists have not thought through which description they would like in each case. See Notes 2026-10-16 · AA meeting with Greg #38.
- Earlier, 14 October, Greg said both invoice styles "contain the booking description unfiltered"; the 16 October invoice description supersedes that. See Notes 2026-10-14 · AA meeting with Greg #6.

Recommendation: the invoice prints the Procedure's invoice description. It starts as the Contract line's description where the line has one, otherwise as a copy of the Booking's description. Proposed by us, not discussed: the office can edit it at review. Not decided: the anaesthetists have not thought through which description they want in each case (including the hospital's description when the hospital is billed), and Greg leaves what an RVG-only pick prints to the developers.
