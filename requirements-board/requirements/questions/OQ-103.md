## Answer

A series of overriding defaults, and the office can always edit the result (Greg's hierarchy, 23 October; confirmed by Donald, product owner, on 4 November for now). The Procedure's [invoice description](US-08.4.6):

- starts as the surgeon's rooms' description, which is always there;
- is replaced by the hospital's description whenever the hospital sends one, whoever is billed; until one arrives, or if none ever does, the rooms' text stays;
- where the chosen Contract line has an invoice description filled in, takes that instead.

AA admins can edit it at any time, as free text. The received texts, the rooms' and the hospital's, are never changed. The RVG code plays no part: when only an RVG code was picked (No contract (RVG), or a hospital's plain RVG Contract), the invoice carries the rooms' or the hospital's description, never an RVG group name. This adds the hospital's description between the two layers agreed in principle on 16 October, and takes in Donald's earlier idea of the hospital's own description when a hospital is billed.

- Greg, 23 October: "I would suggest that we set this up as a series of overriding defaults. So we start with the surgeon's description, we replace it with the hospital description if we get one. And if we've got a contract description, we use that." "So it's three layers and there's a priority." The hospital cannot be relied on to send one: "It depends on the hospital. Some do, some don't."
- Donald, on the Contract line: "our contracts could have a line in here that if filled in, applies a description to the invoice"; Greg: "That's right."
- The office can always change it. Donald: "the admin staff may still want to override that with some free text"; Greg: "absolutely. That stays with the rule that says the admins can change anything."
- When only an RVG code was picked, Greg: "the RVG code isn't in the selection hierarchy that would replace the surgeon's"; "The surgeon always writes what he's going to do."
- Greg wanted the order put to Ben and Vanessa: "do you agree with this hierarchy of selection?" Donald: "Yeah, totally." It was not raised with them on 27 October.
- Donald, 4 November, confirming it for now: "For now, let's say that we will use the text from the hospital by default, but at any time, AA admins can edit. Free text." "If a contract line in the system has a filled in 'Invoice Description' then that becomes the default on the invoice." It has not yet been put to Ben and Vanessa.
