When the change comes from an anaesthetist, do we want to automate the email.

Today the [update email](US-02.3.3) is drafted on demand by an admin and the system sends nothing; when an anaesthetist moves their own List, the office is notified and offered the cover-change email. Donald wondered whether, for an anaesthetist's own move, "it might be an automated email"; Greg: "I agree with you about that." Raised for AA to decide.

## Answer

Manual in the MVP, automated later. Vanessa: "An automated email would be wonderful, because doing it manually is time-consuming." Donald proposed it stays "a manual action in the MVP, even if automation is desirable later", following Greg's view that at go-live "it may be better to keep some manual intervention points. As we discover edge cases and you build trust in the system, we can automate more." Vanessa: "That's fine as long as we've got the option to add it later on." Donald asked for a new story "to automate this functionality in a future phase of work, but not as part of the MVP."

The meeting put the question in terms of changes the admin team makes, while this question asks about changes from an anaesthetist; the answer was given for that framing. (See "Notes 2026-10-07 · AA client meeting #11 #13 #25 #39")
