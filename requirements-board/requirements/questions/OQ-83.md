So far only an account login for the anaesthetists' PWA is assumed (Greg: "what's the experience going to be when the anaesthetist brings up the app on the phone?").

**Still to answer, for Donald:**

1. **Which platforms are supported?** A PWA first, with a native app later or not at all.
2. **Can anaesthetists sign in with biometrics?** A native app can use Face ID or a fingerprint; a standard PWA probably cannot.
3. **Is MFA required for anaesthetists?** The RFP response recommends it enforced for admin accounts.
4. **Is single sign-on offered, for example with a Google account?** It needs higher Auth0 tiers; the RFP response proposed Google and Apple social login on mobile.
5. **Which identity provider?** Auth0 (Stratos' default) or Microsoft Entra External ID (the RFP response).

Recommendation: define the deployable platforms first, then the experience (Donald: "first we need to define this type of deployable platform").
