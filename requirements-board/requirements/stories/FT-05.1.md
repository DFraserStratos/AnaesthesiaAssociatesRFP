The reference data every price starts from:

- the NZSA RVG 2021 groups as published, each with its anatomy heading, plus AA's own groups
- the modifier list

The office maintains them, and every change is recorded.

This is so every RVG code has a published starting point for its base units, found by a type-ahead on code and description.
