The system imports hospital bookings, however each hospital provides them.

This is so its rows appear on the [matching screen](US-02.1.2), ready to be matched to Lists and Bookings.

## Notes

How each hospital provides its bookings is for the integration team to establish (OQ-13). A download holds only for [HL7 v2](FT-14.1); [FHIR](FT-14.2) is a REST interface, so this story speaks of importing bookings rather than a file or download.
