Each hospital's bookings reach the [matching screen](US-02.1.4) as the hospital sends them, however it provides them. Nobody imports a file.

This is so the hospital's rows are ready to be matched to Lists and Bookings as soon as they are sent, with no step for the office to remember.

## Acceptance criteria

- **No import step.** Given a hospital sends its bookings, then its rows appear on the matching screen without anyone importing a file.

## Notes

How each hospital provides its bookings is for the integration team to establish (OQ-13). A download holds only for [HL7 v2](FT-14.1); [FHIR](FT-14.2) is a REST interface, so this story speaks of bookings reaching the screen rather than a file or download.

Until 26 November an admin imported each hospital's file. Donald, 26 November (for the build; not yet seen by AA): "I don't think we are planning to have any sort of ... ingest button."
