On a Procedure, both the Admin App and the Anaesthetist App list all its events: pre-op, post-op, [additional invoices](US-08.6.3) and credits. A refund can also show here as an event: a record of a refund made outside the system (a [credit note](US-08.6.5) is not a refund), not a payment the system makes. The exception is a cancelled prepayment, whose refund the system makes itself ([cancellation of prepayment procedures](US-06.5.2), OQ-115).

This is so the Procedure's history is in one place.

## Acceptance criteria

- Given a Procedure with a post-op event and an additional invoice, when it is opened, then both show in its events.
- Given a [credit note](US-08.6.2) against its invoice, then the credit shows as an event.

## Notes

Tagging an event pre-op or post-op is done in one generic place in the UI.
