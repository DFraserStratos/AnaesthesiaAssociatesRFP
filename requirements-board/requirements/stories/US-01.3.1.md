The Scheduling Engine enforces that an assigned List has exactly one surgeon and exactly one hospital.

Because this pairing is set per List rather than per day, an anaesthetist's AM and PM Lists on the same day need not match. Admins can assign them to different surgeons, different hospitals, or both.

This is so every Booking on a List inherits an unambiguous location and surgeon.

## Acceptance criteria

- **AM and PM can differ.** Admins can assign an anaesthetist's AM and PM Lists on the same day to different surgeons, different hospitals, or both.
