Each Procedure holds an invoice description, the wording its invoice prints. AA admins can edit it at any time as free text. Otherwise it is set by defaults, each replacing the one before:

1. the surgeon's rooms' description, which is always there;
2. the hospital's description, when one arrives;
3. the [chosen Contract's invoice description](US-04.2.18), where it has one.

This is so the invoice carries wording a patient can understand: the rooms' wording is often abbreviated or garbled, not every hospital sends something better, and a Contract's own description is the one AA can be sure of.

An admin's edit always wins: a hospital description arriving later, or a change of Contract, does not replace it. The invoice description is a field of its own, so it never changes the Procedure's [procedure text](US-02.5.7).

The RVG code plays no part. On No contract · RVG or a hospital's plain RVG Contract, the invoice description is the rooms' or the hospital's.

## Acceptance criteria

- **Rooms' description to start.** Given a Procedure with the surgeon's rooms' description and no hospital description yet, and no Contract invoice description, then the invoice description is the rooms' description.
- **Hospital's description replaces it.** Given a Procedure with no Contract invoice description, when the hospital's description arrives, then the invoice description becomes the hospital's description.
- **No hospital description.** Given the hospital never sends a description, then the invoice description stays the rooms' description.
- **Contract's description.** Given the chosen Contract has an invoice description filled in, then the invoice description is the Contract's, whether or not the hospital's description has arrived.
- **Blank on the Contract.** Given the chosen Contract's invoice description is blank, then the invoice description is the hospital's description where one has arrived, otherwise the rooms'.
- **Not from the RVG code.** Given only an RVG code was chosen, then the invoice description is the hospital's or the rooms' description, never taken from the RVG code or its group.
- **Admin edit.** Given an AA admin edits the invoice description as free text, then the invoice prints the edited wording.
- **Edit wins over a late description.** Given an admin has edited the invoice description, when the hospital's description arrives, then the edit stays.
- **Edit wins over a Contract change.** Given an admin has edited it, when the Contract is changed, then the edit stays.
- **Procedure text unchanged.** Given any invoice description, edited or not, then the Procedure's procedure text and its history are unchanged.
