Each Procedure holds an invoice description, the wording the invoice prints, kept apart from the descriptions received from the surgeon's rooms and the hospital ([kept as received](US-02.5.7)). It starts as the Contract line's description where the chosen line has one, otherwise as the Booking's description. It is a field of its own, so the received texts are never replaced. What it says when only an RVG code was chosen is open (OQ-103).

This is because the received wording is often abbreviated and means little to a patient, and Ben prefers a Contract line's own description on the invoice where one applies.

## Acceptance criteria

- Given a Procedure on a Contract line with a description, then the invoice description is the line's description.
- Given a line with no description, then it is the Booking's description.
- Given an invoice description, then the descriptions received from the rooms and the hospital are unchanged.

## Notes

Greg: "I don't think we should ever replace the description. We should have an invoice description field"; Donald: "having an invoice name field... makes sense to me". Greg called it "a new idea". What it should say for an RVG Contract, and whether to use the hospital's description when the hospital is billed, is OQ-103.
