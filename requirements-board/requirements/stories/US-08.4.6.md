Each Procedure holds an invoice description, the wording the invoice prints, kept apart from the descriptions received from the surgeon's rooms and the hospital ([kept as received](US-02.5.7)). It is set by a series of defaults, each taking the place of the one before:

1. it starts as the surgeon's rooms' description, which is always there;
2. the hospital's description replaces it whenever one arrives; until then, or if none ever arrives, the rooms' text stays;
3. where the chosen Contract line has an invoice description filled in, that becomes the default instead.

AA admins can edit the invoice description at any time, as free text. It is a field of its own, so the received texts are never changed.

The RVG code plays no part. Where only an RVG code was chosen, on No contract (RVG) or a hospital's plain RVG Contract, the invoice description is still the rooms' or the hospital's description.

This is because the rooms' wording is often abbreviated or garbled and means little to a patient. The hospital may send something better, but not every hospital does. A Contract line's own description is the one AA can be sure of, and Ben prefers it on the invoice where one applies.

## Acceptance criteria

- **Rooms' description to start.** Given a Procedure with the surgeon's rooms' description and no hospital description yet, and no Contract line invoice description, then the invoice description is the rooms' description.
- **Hospital's description replaces it.** Given a Procedure with no Contract line invoice description, when the hospital's description arrives, then the invoice description becomes the hospital's description.
- **No hospital description.** Given the hospital never sends a description, then the invoice description stays the rooms' description.
- **Contract line's description.** Given the chosen Contract line has an invoice description filled in, then the invoice description is the line's, whether or not the hospital's description has arrived.
- **Blank on the line.** Given the chosen Contract line's invoice description is blank, then the invoice description is the hospital's description where one has arrived, otherwise the rooms'.
- **Not from the RVG code.** Given only an RVG code was chosen, then the invoice description is the hospital's or the rooms' description, never taken from the RVG code or its group.
- **Admin edit.** Given an AA admin edits the invoice description as free text, then the invoice prints the edited wording.
- **Received texts unchanged.** Given any invoice description, edited or not, then the descriptions received from the rooms and the hospital are unchanged.
