On the booking screens, each Procedure shows:

1. **As received**: the surgeon's rooms' description and, when it arrives, the hospital's description, each exactly as sent ([kept as received](US-02.5.7))
2. **Contract**: its name and [holder](US-04.1.5), who is invoiced, and its pricing basis with the figure, for example "Fixed $2,400", "10% off RVG" or "RVG"
3. **RVG code**, where the Contract prices from RVG units (it is not needed when the Contract fixes the price)

It also shows the **invoice description** that will print ([invoice description](US-08.4.6)).

The Contract is chosen before the RVG code, because a fixed price or rate on the Contract can make the RVG code unnecessary. The apps need not show this the same way: a larger screen can break a Booking into more fields than the anaesthetist sees on a phone.

This is because the source wording is not plain English: rooms and hospitals send short codes and snippets, in endless variety, that someone who knows the work can read. Room text is often abbreviated ("WLE MM", "RTK"), while hospital lists are often fuller ("wide local excision", "right total knee"), and the person checking the match needs to see both. The invoice prints the invoice description, which starts from the Contract line's description where there is one, otherwise the Booking's description.

## Acceptance criteria

- **Order.** Given a Booking from any source, then each Procedure shows its text as received, then its Contract, then its RVG code where the Contract prices from RVG units.
- **Both apps.** Both apps show the received text, Contract and RVG code, though not necessarily laid out the same way.
- **Contract summary.** Given a Procedure on a fixed-price Contract held by Southern Cross, then the Contract part shows the Contract's name, Southern Cross as holder, who is invoiced, and the fixed price.
- **Not matched yet.** Given a Procedure with no Contract or RVG code chosen yet, then the received text still shows, with the empty parts marked as still to choose.
- **Fuller wording kept.** Given a later hospital update with fuller wording for the same procedure, then that wording is kept and shown too.
