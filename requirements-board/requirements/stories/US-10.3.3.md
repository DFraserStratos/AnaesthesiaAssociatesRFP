Admins maintain, on a settings page, the items that make up the fixed monthly fee and the charge per invoice. Several items may make up the fixed fee.

The [monthly fee invoice run](US-10.3.1) uses these settings, so a change to a rate needs no change to the system.

## Acceptance criteria

- Given fixed fee items and a per-invoice rate, when the monthly run is made, then the fee invoice total is the sum of the fixed items plus the rate times the number of [BCTIs](US-09.1.4).
- Given a change to a rate, when the next monthly run is made, then it uses the new rate.
