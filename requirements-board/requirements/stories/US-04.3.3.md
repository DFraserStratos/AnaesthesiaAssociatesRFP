Every procedure can be priced on "No contract (RVG)": standard RVG pricing, BTM units x [the anaesthetist's own unit value](US-05.2.1), with no special arrangement. It is available for every procedure, appears first in the [Contract list](US-04.3.2), and is what a Procedure uses where no other arrangement applies. It bills the [payer named on the Booking](US-11.2.2): the patient, or a parent or guardian.

Behind the scenes the system stores it as a Contract like any other, held by AA, [whose holder is never billed](US-04.2.1), so every Booking is priced the same way. It is found by being the one default Contract, never by its name. Users never need to know.

Picking an RVG code on it is optional for the office; the anaesthetist picks one to set the base units. Insured patients who claim the money back themselves are billed under it.

There are no hospital, insurer or procedure default Contracts, and nothing is derived from the List's location.

This is so a Procedure is never left without pricing rules to fall back on.

## Acceptance criteria

- Given any procedure, when the Contract list opens, then No contract (RVG) is first.
- Given No contract (RVG), when the Procedure is priced, then the price is BTM units x the anaesthetist's own unit value.
- Given No contract (RVG), when the Procedure is billed, then the payer named on the Booking is invoiced.
- There is exactly one No contract (RVG), held by AA, and it carries no prices.
