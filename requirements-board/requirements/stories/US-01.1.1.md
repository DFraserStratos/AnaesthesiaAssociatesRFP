The Scheduling Engine creates two Slots, an AM and a PM Slot, for every active anaesthetist for every day across the rolling horizon (four months in current practice), even when no List is attached and nothing is booked.

Each new Slot starts as free. Slots are created even when the anaesthetist is free or unavailable, so the views can show every anaesthetist.

This is so the Admin team always have somewhere to make bookings, and the calendar shows a complete picture with no gaps.

## Technical discussion

Every Slot is stored, empty ones included (OQ-64; Greg: "the foundation on which everything else is painted"). Lists with no anaesthetist ([Draft Lists](FT-01.6)) show too.

The generation run, as Greg described it:

1. writes an AM and a PM Slot, as free, for every active anaesthetist
2. then paints the [anaesthetist's own calendar](US-01.5.3) (holidays and other unavailability) first, then the surgeons' [recurring bookings](US-01.3.2) on top (Donald; Greg: "Yes")

A surgeon's recurring booking that lands on a Slot the anaesthetist has already marked unavailable becomes a Draft List for the office to resolve (OQ-81).

## Notes

About 85 x 120 x 2 = 20,000 Slot records at current roster size.

One List per Slot stays. An anaesthetist who does two hospitals in one half day handles it outside the system today (the second is often a charity hospital, which is not billed). Supporting several Lists in a Slot was judged not worth the complexity for now; it can change later if it does not work in practice.

On 5 November Vanessa and Ben raised sessions shared by two surgeons, and Lists run after the PM session for emergency cases. Donald's working idea for the first is to split the Slot into an A and a B List ([split a session between two surgeons](US-01.1.5)), which would be the one exception to one List per Slot; the second is an [out-of-hours List](US-01.1.6). Until the split is agreed, this story's rule stands.

Every anaesthetist has an AM and a PM Slot every day; the office may open a third, out-of-hours Slot for an anaesthetist on a day ([out-of-hours Lists](US-01.1.6)). The Scheduling Engine never generates that one, so the two generated Slots are still AM and PM only.
