Admins and anaesthetists choosing a Contract are offered only the Active Contracts that fit the Booking's List:

- held by the List's hospital
- or linked to the List's surgeon or anaesthetist
- or an unlinked Contract held by AA, an insurer or a funder

In every case its specialties include the List surgeon's, or it has none, and a fixed price has a price range in force on the List's date.

This is so the choice stays short and relevant, rather than showing every Contract AA holds.

There is no "show all". Insurance on the Booking ([insurer and approval number](US-11.4.3)) never removes a Contract (OQ-93); the Booking's funder only [suggests a path](US-04.3.10). The order in which they are offered is the [step rail](US-04.3.8).

A surgeon's arrangement is one Contract linked to one or more surgeons, held against those surgeons, not their rooms. It is found by the practitioner ID of any surgeon it is linked to, so it is offered on a Booking with any of them, whichever anaesthetist does the work. An anaesthetist sees only their own price list Contracts, never everyone's, and a St George's Contract never shows on a List at another hospital.

Typing finds Contracts by name, holder reference code, invoice description, [AA code](US-04.1.4) and default RVG code. A fixed-price Contract needs no RVG code.

## Acceptance criteria

- **Filters.** Given a Booking's List, then the only Contracts offered are Active ones held by the List's hospital, linked to its surgeon or anaesthetist, or unlinked and held by AA, an insurer or a funder, whose specialties include the List surgeon's or are empty, and, for a fixed price, with a price range in force on the List's date.
- **Surgeon's arrangement.** Given a Contract linked to surgeon S, when a Booking with surgeon S is set up, then it is offered whichever anaesthetist holds the Booking; on another surgeon's Booking it is not offered.
- **One Contract, several surgeons.** Given one Contract linked to surgeons S and T, when a Booking with surgeon S or with surgeon T is set up, then that same Contract is offered, found by that surgeon's practitioner ID.
- **Own price lists.** Given anaesthetist A's Booking, then anaesthetist B's own price list Contracts are not offered.
- **Specialty.** Given a List for ophthalmologist Anna Whitcomb, then a Contract whose only specialty is plastic surgery is not offered.
- **Disabled.** A Disabled Contract is never offered.
- **No show all.** There is no control to show Contracts outside these rules.
- **RVG lookup.** Given RVG code H3 is typed, then Contracts whose default RVG code is H3 are found (agreed in principle; Ben has not yet been asked).
- **AA code search.** Typing a Contract's AA code filters the list to that Contract.
- **Holder code search.** Typing a holder reference code (for example 8942) filters the list to the Contracts carrying it.
- **Composite search.** One search finds Contracts across the name, the invoice description and the codes.

## Technical discussion

The candidate rule is the proposal's [candidates for a List](AR-58#L415-431). A Contract held by a hospital carries no links and is offered only on its own hospital's Lists, and only a Contract held by AA, an insurer or a funder may be unlinked. A specialty matches on any overlap. Open-price fallbacks are never listed; they are reached only through the "Other price" toggle ([open-price fallbacks](US-04.3.9)).
