Admins and anaesthetists picking a Contract for a Procedure see only the Contracts relevant to it:

- "[No contract (RVG)](US-04.3.3)" first, always
- then the Contracts with a line for the picked procedure (a [combination Contract](US-04.2.11) has a line under each of its parent procedures), [valid on the procedure date](US-04.2.10), whose [holder](US-04.1.5) fits the Booking: the List's hospital, the surgeon or rooms, and the Booking's anaesthetist for first-party Contracts

When the user reached the list from an RVG code rather than a procedure, it offers No contract (RVG) first, then the Contract lines for every procedure in that code's group, under the same holder and date filters, each showing its procedure. Picking a line also sets the Procedure's procedure; picking No contract (RVG) sets the group's general procedure.

An anaesthetist sees only their own first-party Contracts, never everyone's, and a St George's Contract never shows on a List at another hospital. The Contracts are shown in one list, with headings by contract holder. Staff may also start from the contract holder, which narrows the list to that holder's Contracts.

This keeps the picker short and relevant, rather than showing every Contract AA holds.

## Acceptance criteria

- **Filters.** The list shows No contract (RVG) first, then only the Contracts with a line for the picked procedure, valid on the procedure date, whose holder fits the Booking's hospital, surgeon or rooms and, for first-party Contracts, anaesthetist.
- **First-party.** Given anaesthetist A's Booking, then anaesthetist B's first-party Contracts are not offered.
- **From an RVG code.** Given the user picked RVG code H3 rather than a procedure, then the list shows No contract (RVG) first, then the fitting Contract lines for every procedure in H3, each naming its procedure; picking one sets that procedure, and picking No contract (RVG) sets H3's general procedure.
- **AA code search.** Typing a Contract's [AA code](US-04.1.4) filters the list to that Contract.
- **Holder code search.** Typing a holder's own code (for example 8942) filters the list to that Contract.
- **Composite search.** One search finds Contracts across the holder, the Contract's name and the codes.

## Technical discussion

The draft technical design offers No contract (RVG) by rule, not by looking up a line, since it has no lines, and leaves the exact context rules open ([AR-29 p6](AR-29#p6)). It is a draft and may change before the catch-up build.
