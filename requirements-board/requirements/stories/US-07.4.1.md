A List leaves the anaesthetist's [main view](US-07.4.2) once the office authorises it. It does not leave when the anaesthetist submits it, and not when payment is received.

Its invoices then appear as lines in the anaesthetist's [outstanding balances](US-12.2.1). The List stays findable afterwards, through [search](US-03.1.6), by patient name first, NHI or date.

This is so the main view holds only work still in progress, while the anaesthetist can still look back at what they entered when an old invoice is queried.

## Acceptance criteria

- Given a submitted List not yet authorised, then it still shows on the anaesthetist's main view.
- Given an authorised List, then it no longer shows on the main view, and its invoices show in the anaesthetist's outstanding balances.
- Given a List that has left the main view, when the anaesthetist searches for it or opens its day, then they can still open it and its Bookings.

Greg (19 October): the new invoices should show in the outstanding balance quickly. Xero returns an ID when the invoice is inserted, so it is "synchronous effectively"; Greg first expected an overnight-refresh delay, but dropped it once he saw the ID comes back at once.
