Where a Procedure's Contract prices from RVG units, the anaesthetist picks its [RVG code](US-05.1.1) with a type-ahead: typing "H1" narrows straight to it, and each row shows the code, its short description and its base units, since the same code can appear with different values. The code fills in the Procedure's starting units, which the anaesthetist can then change.

This is so the code and units come from the anaesthetist's own selection and professional judgement: the procedures actually performed are too varied for the system to work out the right code, or the right figure within a ranged code, on its own.

Rules:

- On a Contract priced from RVG units the RVG code is required, because it sets the base units; the office may leave it blank at [booking setup](US-04.3.4) for the anaesthetist. On a fixed or open price it is optional, for reference only ([RVG detail follows the pricing kind](US-03.3.9)).
- Where the Contract carries a [default RVG code](US-04.2.18), it is filled in when the Procedure has none.
- Base units start from the RVG code, and modifier units start at 0 plus any modifier the system applies ([age or included modifiers](US-03.3.4), OQ-95). From then on they are values on the Procedure.
- The anaesthetist may change base and modifier units to any value they see fit, including one outside the published range; an out-of-range value warns the office and is never blocked.
- [Changing the Contract](US-03.4.1) clears a typed price and keeps recorded units.

## Acceptance criteria

- **Type-ahead.** Given the RVG code field, when the anaesthetist types a code such as "H1", then the list narrows to it, each row showing the code, its short description and its base units.
- **Required on RVG.** Given a Procedure on an RVG Contract, then it cannot be completed without an RVG code; on a fixed-price Contract it can.
- **Default from the Contract.** Given a Contract with a default RVG code, then that code is filled in on the Procedure.
- **Starting units.** Given an RVG code, then the base units are its base units, and modifier units start at 0.
- **Reset on Contract change.** Given the anaesthetist changes the Contract, then a typed price is cleared and recorded units are kept.
- **Ranged base code.** When the RVG code has a unit range, for example 6 to 8 rather than one fixed number, the anaesthetist is shown the range and chooses the exact base unit value.
- **Out of range.** Given base units outside the code's published range, when saved, then the value is accepted and an after-procedure warning is raised for the office ([warning routine](US-13.7.1)).

## Technical discussion

Greg's technical design v6 holds the published base units on each RVG group and keeps on the booking procedure the values the anaesthetist recorded at time entry, where base and modifier units are optional; the catalogue now requires the RVG detail on a Contract priced from RVG units ([RVG detail follows the pricing kind](US-03.3.9)).
