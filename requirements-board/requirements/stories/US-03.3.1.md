The office normally sets the Procedure's Contract at [booking setup](US-04.3.4); the anaesthetist sees it and [can change it](US-03.4.1). Where the Contract prices from RVG units, the anaesthetist picks the [RVG code](US-05.1.1) with a type-ahead: typing "H1" narrows straight to it, and each row shows the code, its short description and its base units, since the same code can appear with different values.

The RVG code is optional: it is not needed when the Contract fixes the price, and the office leaves it blank when it does not know. On an RVG Contract it is good practice, because it is how the base units are set. Where the [Contract line](US-04.2.4) carries a default RVG code, it is filled in already.

Choosing the Contract and the RVG code fills in the Procedure's starting values:

- base units from the RVG code, or from the Contract line where the line states its own
- modifier units, which start at 0 plus any modifier the system applies ([age or included modifiers](US-03.3.4), OQ-95)
- any price, rate or discount from the Contract line

From then on they are values on the Procedure. The anaesthetist may change base and modifier units to any value they see fit, including one outside the published range; an out-of-range value warns the office and is never blocked. Changing the Contract resets these values to the new Contract's.

This is because the range of procedures actually performed is too varied for the system to derive the right code, or the right figure within a ranged code, on its own. The anaesthetist's own selection and professional judgement, from the RVG list, is the reliable source.

## Acceptance criteria

- **Type-ahead.** Given the RVG code field, when the anaesthetist types a code such as "H1", then the list narrows to it, each row showing the code, its short description and its base units.
- **Optional.** Given a Procedure on a fixed-price Contract, then it can be completed without an RVG code.
- **Default from the line.** Given a Contract line with a default RVG code, then that code is filled in on the Procedure.
- **Starting units.** Given an RVG code, then the base units are its base units unless the Contract line states its own, and modifier units start at 0.
- **Reset on Contract change.** Given the anaesthetist changes the Contract, then the price, rate, discount and starting units reset to the new Contract's.
- **Ranged base code.** When the RVG code has a unit range, for example 6 to 8 rather than one fixed number, the anaesthetist chooses the exact base unit value.
- **Out of range.** Given base units outside the code's published range, when saved, then the value is accepted and an after-procedure warning is raised for the office ([warning routine](US-13.7.1)).

## Technical discussion

The technical design v6 holds the published base units on each RVG group, lets a Contract line state its own, and keeps on the booking procedure the values the anaesthetist recorded ([time entry](AR-29#time-entry)); base and modifier units are optional for the user at time entry.
