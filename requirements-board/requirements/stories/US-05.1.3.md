Each [RVG group](US-05.1.1) carries the anatomy heading the NZSA guide prints it under, for example Head. AA can add its own groups beside the published ones.

This is so each RVG code keeps its published place in the NZSA guide.

## Technical discussion

The technical design v6 holds the anatomy as a published field on each RVG group ([RVG group fields](AR-29#rvg-group-fields)), and has no body section, group, procedure picker.
