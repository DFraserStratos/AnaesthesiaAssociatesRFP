The Billing/Invoice Engine has a single integration point with the scheduling system: [a List reaching AUTHORISED](US-07.3.1). It takes no action on a Booking or Procedure before then, with one named exception:

- where the office picks a [prepaid Contract](FT-06.2) for a Procedure, a [prepayment invoice](US-06.3.1) is generated when an admin approves it, before the List is AUTHORISED, and only then sent.
