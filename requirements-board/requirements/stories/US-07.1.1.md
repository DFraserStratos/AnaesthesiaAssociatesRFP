The anaesthetist can submit a List as 'Completed' once every Booking on it is [marked as complete](US-03.6.1). The List then has the status [SUBMITTED](FT-07.2).

This is so the office receives a List for review only once the anaesthetist has finished it.

While any Booking is still incomplete, the system blocks the submit and shows the anaesthetist [what is still missing](US-03.6.2), so they know what to finish.

## Acceptance criteria

- **Incomplete List.** Given a List with any Booking still incomplete, when the anaesthetist tries to submit it, then the submit is blocked and the system shows [what is still missing](US-03.6.2).
