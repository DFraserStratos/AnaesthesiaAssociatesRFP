Admins load the modifier list as master data. It is AA's own list, made of:

- the [RVG modifier table](AR-16#p12): 30 codes on RVG pages 12 to 13, covering pre-assessment, age, ASA and emergency, BMI, awake intubation, P1 non-supine positioning, vascular monitoring, echo, recovery, additional anaesthetist, post-operative cover and nerve catheters
- the modifiers AA uses that are not in the RVG (Vanessa's list)

Each modifier holds its units as the RVG prints them. Some values are not one number, for example "2 + Time", "4-6", "1 per call" or a cap, so a modifier's value needs more than a single figure. Some codes repeat across RVG tables (A1, A2 and P1 are also base codes), so a code alone is not a key.

Only the [age modifiers](US-03.3.8) are pre-applied, from the patient's age, and a modifier already [included in a code's base units](US-05.1.4) shows selected at 0. None is locked: the anaesthetist can remove any of them. All others are [the anaesthetist's choice](US-03.3.4).

This is so the anaesthetist picks from one complete list, and the units each modifier adds are the same for everyone.

## Notes

The RVG transcription is `artifacts/files/NZSA RVG 2021 modifiers.md` (AR-34), made 2026-10-07 from the PDF; spot-check it against the PDF before relying on it. The 2021 edition has no page 12 table of typical and maximum modifier values by body area: pages 12 to 13 give one flat value per modifier, so the requirement refers to the RVG modifier table. The guide's sentence about page 12 guidance by body area needs correcting. Also open in the file: frailty is named with no code or units; the RVG's worked example 2 gives BMI 37 two units where the table gives one; and the RVG has no after-hours, weekend or public-holiday loading, so any AA uses comes from Vanessa's list.

Directors, 6 October: "Some RVGs will include modifiers which can't be removed (Age)" and "All else are optional". Pre-applying the age modifier is AA's rule (not locked, Donald 20 October): the RVG leaves all modifying units "at the discretion of the individual anaesthetist". The age bands and stacking are OQ-95. The directors did not name the ASA grade: that the earlier ASA pre-fill is dropped follows from "All else are optional" and is still to confirm with AA.

Ben, 27 October: "age modifier, that's an easy coding thing"; Donald's summary, not contradicted: "outside of... age and some of those position modifiers that are pre-applied with a zero value, everything else just has to be applied by the anaesthetist." Ben did not name the ASA grade. The age bands and stacking are still OQ-95. Ben worries that anaesthetists stack too many modifiers, but treats it as a policy matter, not a system rule: no limit is set.

Vanessa holds the fuller list of modifiers AA uses that are not in the RVG. Position loadings such as sitting (beach-chair) and prone are modifiers, not base units.

Ben, via Greg (14 October), does not think modifiers should be in the build at all, "you're not focusing on the right thing"; Greg would not finalise it and said Ben must confirm. The v6 design keeps modifier units at 0 by default and itemises claimed modifiers with a note.

Greg, 28 October, doubts the modifier master's value against its cost ("it's okay as written... I'm questioning whether it's of value"); no change asked for. He also asked what happened to the ranges on modifiers: some print a range (for example post-operative cover per day, 2 to 6), which a value of more than a single figure covers. OQ-101's answer (29 October) holds a base unit range on the RVG group; it does not cover modifier ranges.
