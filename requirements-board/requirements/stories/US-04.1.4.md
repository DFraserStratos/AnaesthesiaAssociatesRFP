Every Contract carries AA's own unique identifier, alongside any holder codes kept for reference on its [Contract lines](US-04.2.4). Each Contract line also has a system line key, generated and never reused, which keeps a line's identity across versions, and the holder's own reference code where the holder supplies one, unique within the Contract.

Holder codes are kept only for reference, so AA needs its own code to identify each Contract, whose lines run to thousands. The identifier is a short, structured AA code, and admins can [search the Contract list by it](US-04.3.2) (OQ-66).

## Acceptance criteria

- Given a new Contract, when it is saved, then it has a unique short AA code.
- Holder codes are kept for reference and do not replace the AA identifier.
