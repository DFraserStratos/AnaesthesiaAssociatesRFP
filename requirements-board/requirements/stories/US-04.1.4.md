Every Contract carries AA's own unique code, a short structured code. Admins can find a Contract by typing its code on [the step rail](US-04.3.8) (OQ-66).

This is so AA can identify each of its thousands of Contracts. The holder's own code for the item, the [holder reference code](US-04.2.18), is kept only for reference and is not unique, since a holder's codes repeat across items.

## Acceptance criteria

- **Unique code.** Given a new Contract, when it is saved, then it has a unique short AA code.
- **Holder codes.** Holder codes are kept for reference and do not replace the AA identifier.
