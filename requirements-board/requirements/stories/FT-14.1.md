The system receives and parses HL7 v2 SIU messages, the S12 New, S13 Reschedule, S14 Modification and S15 Cancellation types, from hospital PAS systems.

Each hospital's HL7 v2 implementation varies, so the field-level mapping from a message into a [Booking change](FT-02.5) is configurable per hospital rather than fixed.
