The admin dashboard lists open warnings from the [warning routine](US-13.7.1) as a to-do list of things that need attention. An admin clears a warning from the to-do list once it has been dealt with, with the same tick that [resolves a notice](US-13.8.3). A cleared warning is hidden, not deleted, and warnings never expire by themselves. Clearing is optional for a mild warning.

This is so the office has one place to see what needs doing.

## Acceptance criteria

- **Appears.** Given a new warning, when an admin opens the dashboard, then it is on the to-do list.
- **Cleared.** Given an open warning, when an admin clears it, then it leaves the to-do list.
