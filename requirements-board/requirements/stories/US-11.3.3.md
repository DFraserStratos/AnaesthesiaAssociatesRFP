Admins can record follow-up actions and re-send invoices for a patient's outstanding items.

Anyone, office or anaesthetist, can write a free-text note on a List or a Booking, and everyone who opens it sees the note, so a later reader sees what was done or left behind.

This is so an admin's follow-up on an unpaid invoice is tracked in the system, not just remembered.

## Acceptance criteria

- **Shared note.** Given a note on a Booking, when another user opens it, then the note is shown.

## Notes

The original source of this story is unknown (Greg and Donald, 28 October). Greg: "all of those actions around management should allow a note somewhere so that a follow-up reader can see anything that's been left behind or done before." Donald preferred a free-text note on the List or Booking to notes on alerts; Greg: "I'm not precious about that."
