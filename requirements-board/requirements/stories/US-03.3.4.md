Where a modifier cannot be removed (whether any are locked is OQ-95, still open with Ben), the system adds it and shows it selected and locked. These are the only ones it adds:

- the [age modifier](US-03.3.8), from the patient's age
- any modifier the code's base units [already include](US-05.1.4), for example prone positioning (P1) on every neurosurgery code (H7A to H9b, supine and prone variants alike) and every spine code (S1 to S10), shown as a pill selected at 0 units that cannot be unselected, so it cannot be added again

Every other modifier is optional, whichever way OQ-95 goes. The anaesthetist picks each one that applies from the RVG modifier table plus AA's own [modifiers](US-05.1.5), itemised one by one rather than as a combined total, and gives a short explanation for each one they claim.

This is because some Contracts require the itemised breakdown, not just the total units, and insurers ask why a modifier was claimed.

## Acceptance criteria

- **Locked modifiers.** Given a patient in an RVG age band, or a code whose base units include a modifier, when the anaesthetist opens the Procedure, then that modifier is already selected and cannot be removed (subject to OQ-95). An included modifier shows at 0 units.
- **Nothing else pre-filled.** No other modifier is selected for the anaesthetist, whatever the patient's ASA grade or the procedure.
- **Itemised modifiers.** The anaesthetist picks each further modifier that applies, from the RVG modifier table plus AA's own, one by one rather than entering only a combined total. The choices include:
  - ASA grade
  - BMI banding
  - emergency status
  - non-standard positioning
  - awake intubation
  - pre-assessment
- **Explanation.** Given a modifier the anaesthetist claims, when they save, then it needs a short explanation.

## Technical discussion

The technical design v6 itemises modifiers with one modifier note on the booking procedure, required when any modifier units are claimed ("Insurers ask for it"), and holds modifier units at 0 by default ([time entry](AR-29#time-entry)); whether modifiers are ever pre-filled it leaves open. Locked modifiers, if kept, imply a modifier record per Procedure.

The 2021 RVG modifier table (pages 12 to 13) gives one value per modifier, with no typical or maximum values by body area, so the app offers that table rather than guidance by body area.
