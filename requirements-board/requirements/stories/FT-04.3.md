Every Procedure has exactly one Contract.

The user first finds the procedure in a picker with two tabs. Each tab is one scrolling list under body-area headings, as the NZSA guide prints them, with jump-to-section and one search across procedure name, RVG code and system code:

- **Procedures**: by body area, then subgroup, then procedure
- **RVG codes**: by body area (and the guide's sub-heading, such as Ocular), then RVG code, browsing every code as reference rather than only looking up one already known

Then they choose the Contract. "No contract (RVG)" always appears first, for every procedure. It is followed by the Contracts that:

- have a line for that procedure
- are valid on the procedure date
- have a holder that fits the Booking: the List's hospital, the surgeon or rooms, and for first-party Contracts the Booking's anaesthetist

Picking an RVG code rather than a procedure offers the [Contract lines for every procedure in that code's group](US-04.3.2): picking one also sets the procedure, and picking No contract (RVG) sets the group's [general procedure](US-05.1.6).

This is so every Procedure always has a Contract to work from, whichever route the user takes to it, and the choice offered stays short and relevant.

## Notes

Picking the procedure and then a Contract set against it is the simpler model agreed on 2026-10-01 (OQ-53). The RVG codes route was raised with Greg on 7 October ("pick just via RVG"; Greg did not object) and set out by Donald on 8 October, so users can find the right Contract by either route; the tab layout is Donald's starting point for the picker design and testing with AA. Donald wants the prototype to prove the procedure list out, since its viability is still questioned.

Greg asked for this to be written in terms of contract holders. The picker will be a centrepiece of the system and gets its design and testing with AA later (Greg: the current booking screen is "awful"). The directors' concern is misallocated RVG groups and billable parties, and new anaesthetists sending everything back to the office, so it must be easy.

A holder's plain RVG Contracts have no lines; how they are offered for every procedure is OQ-98.
