The Admin App shows the shared notification pool as a panel on the dashboard, beside the [to-do list](US-13.7.2). It lists the active notices, newest first, with a count of how many are active. Each notice says what happened and when. Every logged-on admin sees the same pool.

An alert raised from a List or Booking shows its note, and opening it goes to that List or Booking. An admin [resolves a notice](US-13.8.3) when it has been dealt with.

This is so the whole office sees the same picture of what has changed, and what is still waiting for someone.

The panel's place and layout are Claude's design for AA to check (OQ-79 part 4 was left to design), which is why this story is marked Verify.

## Acceptance criteria

- **Appears.** Given a new notification, when any admin views the pool, then it is there, active, at the top.
- **Not a to-do.** Given a notification, when an admin opens the dashboard, then it does not appear on the [to-do list](US-13.7.2).
- **Shared.** Given two admins logged on, when both view the pool, then both see the same notifications.
- **Count.** Given active notices, then the panel shows how many are active.
