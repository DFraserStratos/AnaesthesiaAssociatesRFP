Each procedure on the [master procedure list](US-05.1.6) has one default RVG Contract, based on the RVG guide and flagged Default, for example "RVG Standard · Face-lift (H3)" with 6 base units. AA can add any number of further, custom RVG-style Contracts to a procedure, each with its own name and base units, for example "RVG Custom · Face-lift Complex (H4)" with 10 base units (NZSA RVG H4 "Complex Procedures" is 10 to 12 units). RVG-style Contracts are always offered in the [Contract picker](US-04.3.2).

The default RVG Contracts are imported from spreadsheets at the start, then maintained by hand, so a rare change to an RVG unit value is applied by hand. Custom RVG-style Contracts are created by AA as needed.

This is so that, with base units living in Contracts, every procedure always has a standard price to start from.

## Acceptance criteria

- Given a procedure on the master list, then it has exactly one default RVG Contract holding its base units, flagged Default.
- Given a procedure, when AA adds a custom RVG-style Contract with its own name and base units, then it is offered in the picker alongside the default.
- Given a Procedure priced on its default RVG Contract, then its base units come from that Contract.

## Notes

Owner decision 2026-10-05: one default per procedure plus any number of named RVG-style variants, replacing the earlier "one or two default Contracts" wording (OQ-62 board answer; in the meeting Donald described one base Contract per procedure). Greg floated linking Contracts to a master code so an RVG change flows through to every Contract under it; not adopted.

How these per-procedure default RVG Contracts relate to each hospital's [RVG Default Hospital Contract](US-04.3.3) is not settled: for example where the hospital default takes its base units from, and which of them the picker offers beyond the always-offered RVG-style Contracts. Greg's possible no-default-Contract model bears on this too (OQ-78).

Retired 2026-10-07: there are no per-procedure default Contracts. The one default is No contract (RVG) (US-04.3.3), and base units live on the RVG group with an optional procedure-level figure (US-05.1.1, US-05.1.6). A named custom RVG variant, for example a complex face-lift at 10 base units under H4, is modelled as a procedure with its own base units (US-05.1.6). A Contract's line can also override base units (draft design), so a custom RVG-style Contract remains possible as an ordinary Contract with line overrides (Greg accepted those, Notes 2026-10-07 · AA meeting with Greg #61).
