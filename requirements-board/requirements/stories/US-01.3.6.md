Admin staff set each anaesthetist's priority tier on the [anaesthetist's page](US-12.1.4), where it sits with their [rate per unit](US-12.1.1) on one card. The tier is changed like every other card on the page: Edit, choose the tier, then Save. A single click never saves it. There are four tiers, highest first:

- **Tier 1:** the directors
- **Tier 2:** shareholders who are particularly helpful
- **Tier 3:** the other shareholders
- **Tier 4:** non-shareholders, and the default

When an admin asks for the available anaesthetists to fill an extra List or to cover one (for example in the [availability finder](US-01.4.2)), the system orders them by tier, highest first. Within each tier the order is shuffled, so the same person is not always at the top. Admin can also filter by tier, both the available anaesthetists and the Anaesthetists list in People.

Only admin staff see or set tiers. Where anaesthetists see available colleagues, including when they move their own List or a single Booking, the order does not follow the tiers.

This is so the directors' wish to give shareholders and helpful team players preference is built into matching, without arguments over the difference between one exact numeric rank and another.

## Acceptance criteria

- **Default.** Given a new anaesthetist, then their tier is Tier 4 until an admin changes it.
- **Ordered by tier.** Given available anaesthetists in several tiers, when an admin asks who can fill a List, then higher tiers are listed before lower ones.
- **Shuffled within a tier.** Given several available anaesthetists in the same tier, then their order varies from one request to the next.
- **Edit and Save.** Given an anaesthetist's page, when an admin picks a different tier on the card with the rate per unit, then nothing changes until they press Save; Cancel leaves the tier as it was, and each save is its own audited change.
- **Filter.** An admin can filter the list of available anaesthetists, and the Anaesthetists list, by tier.
- **Admin only.** Anaesthetists never see tiers, their own or anyone else's, in either app, and their view of available colleagues is not ordered by tier.
