Admin staff set each anaesthetist's offer order on the [anaesthetist's page](US-12.1.4), where it sits with their [rate per unit](US-12.1.1) on one card. The offer order is changed like every other card on the page: Edit, choose the offer order, then Save. A single click never saves it. There are four, highest first:

- **Offer first:** the directors
- **Offer second:** shareholders who are particularly helpful
- **Offer third:** the other shareholders
- **Standard:** non-shareholders, and the default

Where an "Offer order" heading or label sits beside the value (the field on the card, a table column, a filter), it is shortened to First, Second, Third and Standard. Where it stands alone, such as on a row of a picker, it is written in full.

When an admin asks for the available anaesthetists to fill an extra List or to cover one (for example in the [availability finder](US-01.4.2)), the system orders them:

- by offer order, Offer first at the top
- within the same offer order, those with a [preferred pairing](US-13.6.4) with the List's surgeon first
- among anaesthetists with the same offer order and pairing, in a shuffled order, so the same person is not always at the top

Admin can also filter by offer order, both the available anaesthetists and the Anaesthetists list in People.

Only admin staff see or set the offer order. Where anaesthetists see available colleagues, including when they move their own List or a single Booking, the order does not follow it.

This is so the directors' wish to give shareholders and helpful team players preference is built into matching, without arguments over the difference between one exact numeric rank and another, and so anyone reading the setting can tell at once who is offered work first.

## Acceptance criteria

- **Default.** Given a new anaesthetist, then their offer order is Standard until an admin changes it.
- **Ordered by offer order.** Given available anaesthetists with different offer orders, when an admin asks who can fill a List, then Offer first is listed before Offer second, Offer second before Offer third, and Offer third before Standard.
- **Preferred pairing within an offer order.** Given two available anaesthetists with the same offer order, one with a preferred pairing with the List's surgeon, then that one is listed first.
- **Shuffled within an offer order.** Given several available anaesthetists with the same offer order and the same pairing, then their order varies from one request to the next.
- **Edit and Save.** Given an anaesthetist's page, when an admin picks a different offer order on the card with the rate per unit, then nothing changes until they press Save; Cancel leaves it as it was, and each save is its own audited change.
- **Filter.** An admin can filter the list of available anaesthetists, and the Anaesthetists list, by offer order.
- **Short and full names.** Given an "Offer order" heading or label beside the value, then it reads First, Second, Third or Standard; given a value shown on its own, then it reads Offer first, Offer second, Offer third or Standard.
- **Admin only.** Anaesthetists never see the offer order, their own or anyone else's, in either app, and their view of available colleagues is not ordered by it.

## Notes

The four levels were first called tiers. Donald renamed them the offer order on 27 November (for the build; not yet seen by AA or Greg), because "Tier 1 to Tier 4" did not say which end was good: "I'm not sure whether tier 4 is good or tier 1 is good" (Notes 2026-11-27 · Donald offer order #1 #2 #3). This replaces OQ-102's interim labels Tier 1 to Tier 4. Vanessa's provisional names were Gold Elite, Gold, Silver and Bronze (Donald: "We can work out better language"). Shareholder status is assigned administratively.

That anaesthetists' own view of available colleagues is not ordered by the offer order is OQ-113's answer.

The shuffle within a tier was Donald's suggestion and nobody objected, though nobody explicitly agreed it. A numeric rank set by admin was floated by Greg and not taken up; tiers by years with AA were also floated and not taken up.

Editing the offer order in a card, never by a single click, and filtering the Anaesthetists list by it are Donald's choices for the People section (Notes 2026-11-25 · Donald people section #7: "Edit in a card").

Today the office's view of anaesthetists is alphabetical. Our readings (the prototype as shown to Greg on 19 October, Notes 2026-10-19 · AA meeting with Greg #16): preferred pairing orders the anaesthetists within the same offer order, before the shuffle, and the offer order orders them within each of the groups that the [not-preferred pairing warning](US-01.3.5) separates. Greg approved the ordering as shown ("Excellent"), but how the offer order and the pairings combine was not discussed as such.
