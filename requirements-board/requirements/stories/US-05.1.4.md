Where the NZSA RVG says a code's base units already include a modifier, the system shows that [modifier](US-05.1.5) on the Booking already selected, at 0 units, and locked. The anaesthetist cannot turn it off, and cannot add it a second time.

Today this is the non-supine positioning modifier P1 (2 units) on:

- the six Neurosurgery codes: H7A, H7b, H8a, H8b, H9a and H9b, the supine/lateral 'a' codes and the prone 'b' codes alike (H7, H8 and H9 are headings with no base units of their own)
- the fourteen Spine codes: S1 to S10 and their sub-codes

The RVG's P1 row says so ([page 12](AR-16#p12)): "IF not already accounted for (It is included in Spine and Neuro Base units)". The list is in `NZSA RVG 2021 included modifiers.csv` beside the RVG in the data files.

No other modifier is pre-filled from the procedure. The only other modifiers the system applies itself are the [age modifiers](US-03.3.8), from the patient's age; every other modifier is the anaesthetist's choice.

This is so the anaesthetist can see the loading is already in the base units, and cannot charge it twice by accident.

## Acceptance criteria

- **Included modifier locked.** Given a Procedure on code H8a, when the anaesthetist opens it on the Booking, then P1 shows selected, at 0 units, and cannot be turned off or added again.
- **Both variants.** Given a Procedure on a supine 'a' code such as H7A, or a prone 'b' code such as H7b, then P1 is locked at 0 units on both.
- **Nothing else pre-selected.** Given a Procedure on any code not in the included modifiers list, when the anaesthetist opens it, then no modifier is pre-selected from the procedure.

## Notes

Directors, 6 October: "Some RVGs will include modifiers which can't be removed" and "All else are optional". Donald: the prone positioning modifier "should show up for the anaesthetist on their booking already selected with a value of 0 in a way that means it can't be turned off", so "you couldn't accidentally re-add in a prone positioning modifier". The RVG's Neurosurgery and Spine notes read "These Base Units include Loading for Prone Positioning if needed" (pages 7 and 9).

This reverses the 2026-10-02 reading, which it replaces: then Donald said "The modifiers are never included in the base", and a procedure's default modifiers were to be pre-filled so the anaesthetist could untick them, held as a modifiers column on the procedure master. The included modifier now belongs to the [RVG group](US-05.1.1), and there are no procedure default modifiers.

OQ-94 answered (Donald, 8 October): the 'a' (supine) variants include P1 as well as the 'b' variants, and so does every Spine code. The (+2) printed in the Neurosurgery group header is P1's value, the loading the base units include. Donald's example "H7A or H7B, the base units are 10" holds for H7A only: H7b is 12.
