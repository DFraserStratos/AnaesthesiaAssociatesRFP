The office can give each Contract three undated settings:

- **a holder reference code**: the holder's own code for the item (SXAP AP0126, CES HNZCATall, ACC OPT101), printed on the holder's invoices and found by typing on the [step rail](US-04.3.8); it is kept for reference and is not unique
- **an invoice description**, which becomes the Procedure's [invoice description](US-08.4.6) when the Contract is chosen
- **a default RVG code**, which fills the Procedure's RVG code when it is empty and lets typing an RVG code find the Contract

This is so the holder can match AA's invoice to its own item, the patient reads plain wording, and the office finds the Contract by any code it knows.

A holder's schedule document becomes one Contract per item: the item's code becomes the holder reference code and its description the invoice description.

## Acceptance criteria

- **Default RVG code.** Given a Contract with default RVG code H3 and a Procedure with no RVG code, when it is chosen, then the RVG code becomes H3; a Procedure that already has an RVG code keeps it.
- **Found by RVG code.** Typing H3 finds the Contracts whose default RVG code is H3.
- **Holder code.** Typing 8942 finds the Contract with that holder reference code, and the code is printed on the holder's invoice.
