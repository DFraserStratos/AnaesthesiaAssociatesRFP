Welcome. Everything on this board is an example written as a note to you: read these cards, then delete them (see [Delete these examples](US-01.3.3)) and start your own.

The board shows a **catalogue** of requirements kept as Markdown files in `requirements-board/requirements/`. You edit them here, or Claude Code edits them with the skills; both change the same files, and git keeps the history.

An **epic** like this one is a large area of the system. Its **features** sit under it, and each feature's **stories** under that. The [guide](#/about) explains the whole loop.
