As an analyst, I can hand Claude Code a transcript, notes or an email and have the requirements updated from it.

Run `/update-requirements` with the evidence attached. It files a note in `notes/`, answers the questions the evidence settles, adds, rewords or retires items, raises questions for anything left open, and writes a change log in `changes/`. Review the result here, then commit.

Have two transcripts of the same meeting? Run `/transcript-reconciler` first to merge them.
