The build plan is brought up to date whenever the requirements change.

This is so what gets built next always matches what was last agreed.

Commit the catalogue, then run `/update-build-plan` (it takes the commit, or uses the latest). With no plan yet it makes the first one; after that it re-grades only what changed and re-plans the phases it touches. Its folder and your app's folder are set in the skill's "This repo" section.
