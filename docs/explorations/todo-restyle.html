To-do restyle options

Six ways the Admin Day to-do list could look without the curved, darker left edge, plus how it looks today for reference. Every rail works: Open shows where it would go, Clear takes the row away with an undo, and Reset puts the rows back. Each uses the same data: the three warnings from your screenshot, a strong balance warning and a replaced Contract to disable.

Should Open be the primary action? Yes.

US-13.7.2 makes the list "things that need attention". Clearing is how the office says one has been dealt with, and it's optional for a mild warning. Warnings are worked out fresh from the Booking each time, so fixing the cause (adding the approval number, checking the payer, approving the prepayment) takes the warning off the list without anyone clearing it. That makes the usual path Open, fix, gone. Clear is for the exceptions, when the office has handled it somewhere else or decided it doesn't matter.

Today it's the other way round: Open is plain text, and Clear (optional) is the only thing on the row with a border, so your eye goes to it first. All three rows in your screenshot are mild, so the button you're steered to is the one that's never needed.

  • Make Open the primary action, either the whole row or the one filled teal button.
  • Make Clear quiet: a tick icon or a ghost button. Keep it a tick, because the story says it's "the same tick that resolves a notice".
  • Drop "(optional)" from the label. The strength already says how much a warning matters. If you still want the hint, put it in the tooltip.
  • Swap the generic triangle for an icon per rule (payer, insurance, balance, prepayment, Contract), so you can tell what kind of problem a row is at a glance. Strength stays as colour, with the word "Strong" written on strong ones so colour isn't the only signal.
