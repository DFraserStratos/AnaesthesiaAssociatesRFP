Admin app · design exploration · 26 Nov 2026 · second draft

One Finances sectionfor Billing, Invoices, Payments, the Ledger, Xero and AA fees

Today the office's money work is spread over three menu items. The Billing monitor is one page about 15,600px long that does six jobs. Invoices has no paid or unpaid state. The Ledger opens with ten tiles before its table. AA fees and payment runs have no menu item at all.

This is one Finances item with six routed tabs, on the same frame as Contracts and People: the title, the tabs, one toolbar, the list, and a right-hand column for anything that sits beside the list. The tabs follow the office's jobs as the catalogue describes them, not the current screens.

Second draft: nothing new, only the shared kit. The first draft invented a progress bar, a red edge on problem rows, filter pills with counts, an amber filter pill, a blue "info" pill, pill-shaped steps, and notices and tiles stacked above the tables. All of those are gone. Every part is now an existing shared component, drawn as it draws today, and the table near the end names each one and where the app already uses it.

The office's jobs, from the catalogue

Two agents read every live story under EP-08, EP-09, EP-10, EP-06, FT-11.3, FT-13.2 and FT-13.3, the open questions that cite them, and the rulings up to 25 Nov. The same path as Contracts (Phases 45 to 49) and People (50 to 57): a requirements change, then a build plan in phases. The panels already read the store themselves, so most of the work is moving them, not rewriting them, and no shared component changes.
