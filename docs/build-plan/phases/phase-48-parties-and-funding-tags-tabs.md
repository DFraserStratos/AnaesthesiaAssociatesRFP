## Goal

Parties and Funding tags are tabs of the Contracts section, and the office can see how each Party's and each tag's Contracts are spread.

- **Parties tab** (`/admin/contracts/parties`): grouped by kind, Contract-less Parties included (an insurer or funder is also chosen as a Booking's funder). A Party's page (`/admin/contracts/parties/:partyId`) shows its details edited in place and its Contracts counted by funding tag, No tag included; each count opens the catalogue at that holder and tag.
- **Funding tags tab** (`/admin/contracts/tags`): the ordered list (Up, Down), each tag's funder and the audited add, edit and remove, unchanged. Picking a tag shows its Contracts grouped by hospital with each hospital's count, each opening the catalogue.
- **Master data** loses Contracts, Parties and Funding tags, shows a one-line pointer ("Contracts, Parties and Funding tags are now in Contracts"), and the old `?view=parties` and `?view=fundingTags` links redirect.
