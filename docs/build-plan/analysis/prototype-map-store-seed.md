# Prototype map: store + seed

Paths are under `aa-prototype/src/` (`store/` = `aa-prototype/src/store/`, `seed/` = `aa-prototype/src/domain/seed/`). Line numbers are approximate pointers.

**Orientation.** The "backend" is one Zustand store (`store/appStore.ts`, `useAppStore`), persisted to localStorage key `aa-demo` as a delta against the deterministic seed. State = `SeedState` (masters, schedule, audit, settings, appSettings, dayNotes, officePrivate, notifications, patientCare, support, counters) + `clock`, `billing`, `xero`, `integrations`, `intake`, `masterLoads`, `shell`. Every domain write is `mutate(api, actor, metas, recipe)` (`store/mutate.ts`), which appends an audit entry per meta, stamps touched Bookings, runs the conflict reconcile and allocates ids. Actions are plain functions `fn(api, actor, ...) => Outcome` (never store methods), refusing with `refuse(code, message)` and writing nothing. There are no routes in this area: screens call these actions through the `store/index.ts` barrel (~600 exports), with ad hoc `useAppStore(selector)` and a few hooks. The seed is built once per page: core seed (14 anaesthetists) plus 71 colleagues of `seed/fullScale/names.ts` (`scope:'practice'`). The demo day is `DEMO_TODAY = 2026-11-24` (Tue, 08:00), moved 18 weeks in PERSIST_VERSION 78, so many comments, labels and marker `detail` strings still say "Tue 21 July"/"Fri 17 Jul": trust the ISO dates, not the weekday text.

- **Diagnostics** (`diagnostics.ts`): `reportDiagnostic` redacted log; every `refuse()` also logs. `privacyScan.ts` = NHI leak scan (Xero slice must hold zero NHI/PII).

## 2. Lifecycle guards (`store/lifecycle.ts`, 878 lines)

- List states `DRAFT|ACTIVE|SUBMITTED|AUTHORISED` (`domain/types.ts:82`); kinds `private|preop` (`LIST_KINDS`); Session `AM|PM|OOH`. DRAFT lists have no slot/anaesthetist (`DraftList`).

Sets `completed`, `completedAtISO`. `uncompleteBooking` (l.183): amend, same rights.
- `submitList` (l.241): ACTIVE only; not integration/system; own List for anaesthetist; every non-cancelled Booking completed (`bookingsNotCompleted`). ACTIVE to SUBMITTED.
- `authoriseList` (l.301): office only (`officeOnly`); SUBMITTED only (`listNotSubmitted`); `authoriseBlockersFor` (l.407: Procedure on a Contract with `priceStatusFor == needsPrice`, code `needsPrice`, message `AUTHORISE_NEEDS_PRICE`); all Bookings complete; approves pending anaesthetist Contract changes (`approvalsAtAuthorise`, contractApprovalActions.ts:102); takes a pricing **lock** per live Booking (`takeLockFor`, `locks.ts`, `domain/billing/lock.ts`, audited `booking.lock`); SUBMITTED to AUTHORISED; emits `listAuthorised` (not on a draft store) which triggers `runBillingForList`.
- `cancelBooking` (soft cancel; `reasonRequired`, `alreadyCancelled`; settles prepayment in the same commit via `settlePrepaymentOnCancel`, never refuses); `reassignBooking` (`sameList`, `listAuthorised` both ways, `notOwnList`; anaesthetist to a colleague must use Move). Both wrapped as one change set (`cancel`/`move`).
- `editBooking` (only `scheduledTime`,`notes`), `editProcedure` (l.646: refuses modifiers (`modifiersThroughActions`), `usePrimaryAction`, additional-procedure base units, whole-number base units, contract/price/text fields redirect to rail/`setProcedurePrice`/procedure text actions), `editList` (hospital/surgeon/notes; `pairingRequired`), `logListNote` (office only, `textRequired`).
- Warnings are not blockers: rules in `domain/warnings/rules/` (approvalNumberMissing, baseUnitsOutsideGuide, childPayer, patientBalance, prepaymentUnpaid, replacedContractStillActive, splitDoesNotFit), evaluated by `store/warnings.ts` (`warningsForBooking/List`, `openWarnings`, `clearWarning` office only: `notFound`,`alreadyCleared`).
