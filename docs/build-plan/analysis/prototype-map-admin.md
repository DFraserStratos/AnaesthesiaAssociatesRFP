# Prototype map: Admin Web App (aa-prototype/src/apps/admin)

Orientation. The Admin Web App is the office's desktop app, mounted at `/admin` (route table in `aa-prototype/src/router.tsx:119-176`; thin route wrappers in `apps/admin/routes.tsx`). `AdminApp.tsx` is the layout: dark side nav with attention badges, the day-scoped derivations, and three transient overlays (session drawer `SlotDrawer`, Draft List drawer `DraftListDrawer`, `OpenOutOfHoursSheet`) that are state, not routes. Every screen sits on one page frame, `components/AdminPage.tsx` (modes `fit` / `fluid` / `document`; `PageToolbar`, `PageBody` with `rail` or `nav`; measurements in `layout.ts`, 1280px min width). There is no sign-in and no real role switching inside Admin: the app always acts as the office actor from `useAppStore(s => s.shell.officeUser)` (Kirsty W. or Sam T., `store/demoActors.ts:12-43`; swapped by the demo trigger `switch-office-user`). Office-only rules are enforced in the store (`actor.role !== 'office'` refusals, e.g. `store/lifecycle.ts:301`), not in the UI. Everything is a fake in-browser store; there is no `fetch`. **Contracts today are a Master data view (`/admin/masters?view=contracts`, group Billing) opening a side panel; there is no Contracts section, Contract page route, Replace action or Parties / Funding tags tabs under Contracts yet** (see section 5, the focus of phases 45 to 49).

### Contracts in depth (focus of plan phases 45 to 49)

Current shape: one list view plus one side panel; no route per Contract; no Contracts nav section.

- **List** `ContractsView.tsx`: `contractSearch` (domain/billing/contracts.ts:404) over name, holder reference, AA code, default RVG code; filters Active (default) / Disabled / All (`FilterPills`), Holder select (also `?holder=`, reached from a Party's "active" link; opens on All if the holder has no active office Contract, :60-63), Funding tag select; results grouped under holder headings (No contract RVG first), columns AA code, Name (+ holder reference, specialties), Invoicing (`contractInvoicingSummary`: bills holder/payer, layout, delivery; derived, read-only), Pricing (`PricingText`: range in force `rangeSummary`, RVG at rate per unit, RVG less N%), Status and tags (Active/Disabled pill, System pill, funding tag, Prepaid, override pill on RVG kinds). `?contract=<id>` opens the panel then drops the param. "New contract" opens the panel blank (holder prefilled from filter). System / fallback Contracts are filtered out of counts by `isOfficeContract` (`domain/billing/fallbacks.ts:90`).
- **Panel** `ContractPanel` (`ContractEditSheet.tsx:93`, `MasterPanel` side panel, shot `contract-detail`): tabs Details / History (edit only). Sections: Contract (name, AA code, assigned on save from holder `codePrefix` via `nextAaCode` `domain/billing/contracts.ts`), Invoice and codes (holder reference, invoice description, default RVG group via `CodePickerSheet`), Holder and who it bills (holder fixed after save; bills holder/payer; linked surgeons via `ChipMultiSelect`, linked anaesthetist; prepaid fixed after save), Where it is offered (specialties, none = all; one funding tag; `destinationOf`/`destinationHint` live line), Pricing (kind fixed after save: rvgAnaesthetistRate / rvgContractRate (unit rate) / rvgDiscount (%) / fixed; `open` only for system fallbacks; override Yes/No on RVG kinds; fixed = `ContractPriceRanges` + first range for a new one), `ContractEventFees` (office-only fixed fees for pre/post-op event types, `addContractEventFee` etc., audited), and on **create only** a "Replaces" section (`:~507`): optional old Contract + From date.
- **Save** `save()` :212 -> `createContract` (`store/contractActions.ts:158`) or `editContract` (:274) (audits `contract.create`/`contract.update`; system Contracts via `systemPatch` allow only `SYSTEM_CONTRACT_EDITABLE_FIELDS` = name, aaCode, invoiceDescription). Disable / Make active: `toggleStatus` :259 -> `disableContract` :320 / `enableContract` :325, **immediately, no confirm step**; a system Contract offers no Disable. Each create/edit/enable runs `ensureFallbacks` (audit `contract.fallbackCreate`).
- **Replaces is warning-only**: nothing stored or moved.
