For each upcoming Booking that needs prepayment, the admin can see whether it is unpaid, part paid or paid in full.

As the procedure date gets closer, the admin is alerted if the prepayment is still outstanding.

This gives the admin a chance to follow up, or lets the anaesthetist decide to cancel the Booking instead.

## Acceptance criteria

- **No block.** Completing a Booking or List is not blocked by an outstanding prepayment.
- **Both apps.** An outstanding prepayment shows as a clear warning in the Admin App and on the Booking in the anaesthetist's app before surgery, so the surgeon can be told ([warning flag](US-13.7.3)).
- **Alert as the date approaches.** As the procedure date gets closer, the admin is alerted if the Booking's prepayment is still outstanding, so the admin can follow up, or the anaesthetist can cancel the Booking instead.

## Notes

Merges the former US-06.3.3 (Alert on unpaid prepayment), now Retired. Both were Confirmed, so status is unchanged. The status display (unpaid, part paid, paid) and the outstanding alert are the same monitoring capability seen from two angles, and share the same day grid flag.
