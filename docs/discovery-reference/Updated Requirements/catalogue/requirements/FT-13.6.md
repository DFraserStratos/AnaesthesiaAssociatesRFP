Surgeons and surgeons' rooms are master data, not free-text names. Each surgeon belongs to a room, has a profile page, and can be on a blacklist against particular anaesthetists.

This is so the system can hold each surgeon's identifying numbers, know who to contact for a room, and flag anaesthetist and surgeon pairings that should not be matched.

Vanessa will supply the master list of rooms and surgeons; reference data is loaded from controlled spreadsheets rather than migrated (see [reference data from controlled spreadsheets](US-13.4.3)).
