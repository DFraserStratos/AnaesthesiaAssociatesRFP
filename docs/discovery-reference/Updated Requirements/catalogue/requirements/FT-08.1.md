The Billing/Invoice Engine has a single integration point with the scheduling system: [a List reaching AUTHORISED](US-07.3.1). It takes no action on a Booking or Procedure before then, with one named exception:

- where a Procedure matches the [anaesthetist's prepaid list](US-06.1.1), a [prepayment invoice](US-06.3.1) is generated at booking setup, before the List is AUTHORISED, and held for an admin to approve before it is sent.
