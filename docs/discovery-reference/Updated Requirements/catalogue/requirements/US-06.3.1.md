When a Procedure on a Booking matches the [anaesthetist's prepaid list](US-06.1.1), the Billing/Invoice Engine generates the prepayment invoice automatically at booking setup. It is not sent until an admin approves it; it then goes out with a [prepayment letter](US-06.3.6).

Generating it creates a [linked receivable and payable](US-08.3.1) in the internal ledger, and the [matching pair of draft records in Xero](US-09.1.3). A later List submit does not invoice it again.

The invoice is raised only where the billable party is a person paying for the patient, never an organisation (OQ-73).

## Acceptance criteria

- Given a Booking whose Procedure matches the anaesthetist's prepaid list and whose billable party is a person paying for the patient, when the Booking is set up, then a prepayment invoice is generated.
- Given a generated prepayment invoice, when no admin has approved it, then it is not sent.
- Given a prepayment invoice already generated, when the List is submitted, then the prepayment is not invoiced again.
