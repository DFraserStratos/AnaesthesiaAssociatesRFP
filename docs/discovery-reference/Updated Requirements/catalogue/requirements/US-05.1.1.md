Admins load the NZSA RVG code set as master data. For each code, this includes:

- its description
- its section, the anatomical site from the NZSA guide
- its base units, or a range where the guide gives one
- any [positioning loading](US-05.1.4) it already absorbs

This is so the Billing/Invoice Engine has everything it needs to calculate a fee from a code, without any further lookup.

Admins can also add procedure codes that the NZSA guide does not cover, and set their base units. Each of these is marked as AA-sourced, so it stays distinguishable from the standard NZSA set.

## Acceptance criteria

- **AA-added codes.** Admins can add procedure codes that the NZSA guide does not cover, and set their base units. Each is marked as AA-sourced, so it stays distinguishable from the standard NZSA set.

## Notes

Merges the former US-05.1.2 (Add AA codes), now Retired.

Base units cannot always be taken from the RVG code alone, since the same code can appear with different values. Authoritative base units are to be held per procedure on the [Procedure master](US-05.1.6) (the recommendation in OQ-06); this story keeps the guide's own values.
