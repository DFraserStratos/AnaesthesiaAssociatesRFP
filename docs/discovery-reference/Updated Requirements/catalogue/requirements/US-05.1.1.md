Admins load the NZSA RVG code set as master data. For each code, this includes:

- its description
- its section, the anatomical site from the NZSA guide
- its base units, or a range where the guide gives one
- any [positioning loading](US-05.1.4) it already absorbs

This is so the Billing/Invoice Engine has everything it needs to calculate a fee from a code, without any further lookup.

Admins can also add procedure codes that the NZSA guide does not cover, and set their base units. Each of these is marked as AA-sourced, so it stays distinguishable from the standard NZSA set.
