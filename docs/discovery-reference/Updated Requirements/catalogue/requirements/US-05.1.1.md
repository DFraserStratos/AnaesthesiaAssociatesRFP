Admins load the NZSA RVG code set as master data. For each code, this includes:

- A unique system (human readable) code.
- its description
- its section, the anatomical site from the NZSA guide
- its base units, or a range where the guide gives one

This is so the Billing/Invoice Engine has the RVG reference data for each code: its unique system code, description, site and guide base units. The base units it prices from come from the procedure's [default RVG Contract](US-04.4.2).

Admins can also add procedure codes that the NZSA guide does not cover, and set their reference base units.

## Acceptance criteria

- **AA-added codes.** Admins can add procedure codes that the NZSA guide does not cover, and set their reference base units.

## Notes

Merges the former US-05.1.2 (Add AA codes), now Retired. AA-added codes are no longer marked as AA-sourced (2026-10-02): the guide is only a guide, and a code AA adds against the most relevant RVG code is not wrong. Donald: the RVG list is "more just a rough reference, a very slim starting point."

The unique system code is Greg's (from Ben: "Every line needs a unique identifier"): a human readable, quasi-structured code that users see and can start typing to find, distinct from the underlying RVG code, and called a code, not an ID. "System" rather than "AA" because the owner may change. Greg: "We'll come back to it." Whether it belongs on this master or on each line of the [Procedure master](US-05.1.6), and whether the two are one list, is OQ-88.

The RVG guide is only a guide. Donald found it sparse (about 30 entries), and the same code can appear with different base units (a T2 with four or five), so base units cannot be taken from the RVG code alone. AA can set any base units, whatever the guide says. This story keeps the guide's own values.

Where authoritative base units live is settled (OQ-62): in each procedure's [default RVG Contracts](US-04.4.2), not on this master or the [Procedure master](US-05.1.6). This master keeps the guide's own values as reference. Vanessa is filling in a standard procedure list with RVG codes and base units.
