After a [credit note](US-08.6.5) against an invoice, the system copies the original invoice's line items into a draft [additional invoice](US-08.6.3), as the starting point for the rebuild.

This saves the admin retyping the original's lines when they rebill.

## Acceptance criteria

- Given a credit note against an invoice, when the admin starts the rebill, then a draft additional invoice holds the original's lines.
