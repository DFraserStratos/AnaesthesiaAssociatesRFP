Admins and anaesthetists picking a Contract for a Procedure see only the Contracts relevant to it: those set against the procedure picked from the [master procedure list](US-05.1.6) (a [combination Contract](US-04.2.11) sits under each of its parent procedures), narrowed by the List's hospital (and possibly the surgeon, raised in passing and not settled). The [default RVG Contract](US-04.3.3) is always offered as well, so a St George's Contract never shows on a List at another hospital, but standard pricing is always a choice.

This keeps the picker short and relevant, rather than showing every Contract AA holds.

## Acceptance criteria

- **Filters.** The list is filtered by the picked procedure, then by the List's hospital, with the default RVG Contract always offered.
- **AA code search.** Typing a Contract's [AA code](US-04.1.4) filters the list to that Contract.
- **Holder code search.** Typing a holder's own code (for example 8942) filters the list to that Contract.

## Notes

The patient's insurer or funding source is not a filter: neither the Patient nor the Booking holds it, because each Procedure's Contract says who pays (OQ-55). Contracts are expected to number in the thousands; they are kept navigable by the procedure and hospital filters plus code search (OQ-66).
