The Admin App shows the shared notification pool, newest first, and staff page back through older notifications. Each notification says what happened and when. Every logged-on admin sees the same pool.

This is so the whole office sees the same picture of what has changed.

## Acceptance criteria

- **Appears.** Given a new notification, when any admin views the pool, then it is there.
- **Not a to-do.** Given a notification, when an admin opens the dashboard, then it does not appear on the [to-do list](US-13.7.2).
- **Shared.** Given two admins logged on, when both view the pool, then both see the same notifications.
