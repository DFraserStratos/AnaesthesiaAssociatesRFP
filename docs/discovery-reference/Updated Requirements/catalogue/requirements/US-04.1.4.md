Every Contract carries AA's own unique identifier, alongside any holder codes kept for reference on its [fixed fee schedule lines](US-04.2.4).

Holder codes are kept only for reference, so AA needs its own code to identify each Contract among thousands (OQ-66).

## Acceptance criteria

- Given a new Contract, when it is saved, then it has a unique AA identifier.
- Holder codes are kept for reference and do not replace the AA identifier.

## Notes

Ben says Contracts will all need codes; the coding scheme is still to be worked out (OQ-66). Donald has doubts about the model, so it is built for now and validated later.
