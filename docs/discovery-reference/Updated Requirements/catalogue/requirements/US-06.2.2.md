An admin or the anaesthetist sets the prepaid amount on the Booking. By default this is an [estimated full fee](US-06.2.3), [calculated automatically](US-06.2.4) at [the anaesthetist's own unit value](US-12.1.1) (with two contingency modifier units, OQ-38), but it can instead be set as a deposit.

Whichever is chosen, the amount is stored on the Booking.
