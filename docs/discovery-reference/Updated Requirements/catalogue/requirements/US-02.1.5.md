St George's and Southern Cross, the two hospitals integrated today, are in scope for bringing booking data into the [matching screen](US-02.1.2) without an admin downloading it by hand. The particulars of their technical implementation are yet to come.

Matching stays a manual admin review, as it is today. The integration only brings rows in; nothing is applied to a Booking until an admin decides.

This is so the office stops pulling from these two hospitals by hand, and keeps the checking step it relies on (who is on the List, double bookings, changed times, patients appearing and disappearing).

## Acceptance criteria

- **No silent apply.** Given rows have arrived, then every row still goes through the admin's match, create or reject decision, and rows that cannot be matched stay in the [unmatched queue](US-02.1.4).

## Technical discussion

How each hospital delivers its data today is to be confirmed (OQ-13). Vanessa holds a few old emails about the current integrations. Only St George's and Southern Cross are in scope here; the other providers are Future Work ([feeds from the other Christchurch providers](US-14.6.1)).
