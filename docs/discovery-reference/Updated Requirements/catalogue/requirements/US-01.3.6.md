Admin staff set each anaesthetist's priority tier on the anaesthetist's record. There are four tiers, highest first (names provisional):

- **Gold Elite:** the directors
- **Gold:** shareholders who are particularly helpful
- **Silver:** the other shareholders
- **Bronze:** non-shareholders, and the default

When an admin asks for the available anaesthetists to fill an extra List or to cover one (for example in the [availability finder](US-01.4.2)), the system orders them by tier, highest first. Within each tier the order is shuffled, so the same person is not always at the top. Admin can also use the tiers to filter the display.

Only admin staff see or set tiers. Where anaesthetists see available colleagues, the order does not follow the tiers.

This is so the directors' wish to give shareholders and helpful team players preference is built into matching, without arguments over the difference between one exact numeric rank and another.

## Acceptance criteria

- **Default.** Given a new anaesthetist, then their tier is Bronze until an admin changes it.
- **Ordered by tier.** Given available anaesthetists in several tiers, when an admin asks who can fill a List, then higher tiers are listed before lower ones.
- **Shuffled within a tier.** Given several available anaesthetists in the same tier, then their order varies from one request to the next.
- **Filter.** An admin can filter the list of available anaesthetists by tier.
- **Admin only.** Anaesthetists never see tiers, their own or anyone else's, in either app, and their view of available colleagues is not ordered by tier.
