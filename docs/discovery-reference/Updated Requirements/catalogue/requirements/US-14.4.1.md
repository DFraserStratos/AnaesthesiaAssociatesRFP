As the system, I look up and validate patients against the NHI FHIR API and reference anaesthetists by HPI.

## Technical discussion

Proposed in our RFP response: NHI is used only for its intended purpose, with lookups performed against the NHI FHIR API via the Health NZ Digital Services Hub. NHI lookups via the Hub are included in dual-format NHI regression testing, alongside inbound HL7 v2 and FHIR paths.
