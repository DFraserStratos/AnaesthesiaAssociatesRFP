Every Procedure must have exactly one governing Contract before its Booking can be treated as complete.

Admins and anaesthetists pick the procedure, then choose the Contract from those set against that procedure, narrowed by the List's hospital, which is always known. The patient's insurer or funding source is not a filter: neither the Patient nor the Booking holds it, because each Procedure's Contract says who pays (OQ-55).

Where nothing more specific applies, the Procedure defaults to the RVG Default Hospital Contract for the List's hospital, so there is never a case where a Procedure is left without a Contract to work from.

## Notes

Picking the procedure and then a Contract set against it is the simpler model agreed on 2026-10-01 (OQ-53), to be tried in the next prototype.
