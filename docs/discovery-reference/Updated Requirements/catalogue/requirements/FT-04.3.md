Every Procedure must have exactly one governing Contract before its Booking can be treated as complete.

Admins and anaesthetists choose the Contract from a list that is already filtered down to the Contracts relevant to the List's hospital, the surgeon, the patient's insurer or funding, and the RVG code.

Where nothing more specific applies, the Procedure defaults to the RVG Default Hospital Contract for the List's hospital, so there is never a case where a Procedure is left without a Contract to work from.
