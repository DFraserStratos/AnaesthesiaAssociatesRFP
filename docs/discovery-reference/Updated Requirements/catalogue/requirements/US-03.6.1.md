Before an anaesthetist can mark a Booking complete, every Procedure in it must have:

- a procedure, which carries its RVG code, and a Contract
- [its times recorded](US-03.3.3)
- a short explanation for any [modifier claimed](US-03.3.4)
- any [reference the Contract's holder needs](US-04.2.2)

Only once all of this is present can the anaesthetist mark the Booking complete.

## Notes

Whether a Booking set up without a matched procedure can reach this point, and what then blocks it, is OQ-99.
