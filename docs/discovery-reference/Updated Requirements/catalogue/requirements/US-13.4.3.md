The system's reference data is loaded at cutover from controlled spreadsheets that AA owns and has checked, not from Solutions Plus records. Whether admins can re-load it later is to be decided. The spreadsheets cover:

- hospitals
- surgeons and surgeons' rooms
- procedures, with their [RVG mapping and base units](US-05.1.6)
- [modifiers](US-05.1.5) with their units
- [fixed fee schedules](US-04.2.4) and any Contract-specific overrides

Solutions Plus is used only for operation names: its operation list is a starting list of names. Its unit values are not used, and junk entries, such as '10% discount' saved as a permanent operation, are removed before loading.

This is because there are few enough hospitals and surgeons to rebuild clean reference data from a spreadsheet, and the Solutions Plus values are not canonical.

## Acceptance criteria

- Recommendation: given a controlled spreadsheet, when an admin loads it, then rows failing validation are reported and not loaded.
- Recommendation: given the Solutions Plus operation list, when it is used as a starting list, then only names are taken and entries such as '10% discount' are excluded.
