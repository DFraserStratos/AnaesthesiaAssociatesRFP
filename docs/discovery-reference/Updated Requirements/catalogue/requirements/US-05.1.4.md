Some procedure codes specify a default modifier. For example, spine and neuro procedures indicate the prone positioning [modifier](US-05.1.5).

The system records which procedure codes specify default modifiers, as a modifiers column on the [Procedure master](US-05.1.6) beside the procedure's RVG code.

When the anaesthetist captures that Procedure on a Booking, its default modifiers are pre-filled, and the anaesthetist can untick them.

## Acceptance criteria

- **Pre-filled.** Given a procedure code that specifies a default modifier, when the anaesthetist adds that Procedure to a Booking, then the modifier is already selected.
- **Can be removed.** Given a pre-filled default modifier, when the anaesthetist unticks it, then it is not charged.

## Notes

Replaces "absorbed modifiers" (2026-10-02). Modifiers are never included in the base units: they are separate things, and a procedure applies its modifier rather than its base absorbing it (Donald: "this 'absorbing modifiers' is wrong").
