From a current or [past Procedure](US-03.1.6), the anaesthetist adds an event with its own date and time, recording either a time or a fixed fee. Events take no other modifiers.

The event is attached to the original Procedure so it stays traceable. Proposed, pending OQ-63: it shows as its own element.

## Acceptance criteria

- Given a past Procedure, when the anaesthetist adds a post-op event with a time, then it is saved against that Procedure with its own date.
- Given an event, then no modifiers can be added to it.
- An event can be marked not billable.

## Notes

If the work is significant, the anaesthetist creates another Booking instead (Greg). How an event is modelled and what it is called are OQ-63.
