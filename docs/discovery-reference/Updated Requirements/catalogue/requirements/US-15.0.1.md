As any user, the system is intuitive enough for people who are not comfortable with modern systems, especially the operational screens.

## Technical discussion

Proposed in our RFP response: interface design is done in-house by engineers who produce working interfaces, so AA sees real screens during scoping rather than wireframes. Training runs directly with each user group before go-live. Where possible, guidance is embedded in the application so help appears at the point of need and standalone documentation stays short. Ease of use and in-context help are a particular focus.
