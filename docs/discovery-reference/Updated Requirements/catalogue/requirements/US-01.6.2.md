Admins see every Draft List in the Admin App, in a place they will notice, each clearly flagged as a List being prepared and not yet assigned. Each shows its day, session, hospital and surgeon, and how long it has been waiting for an anaesthetist.

This is so an unassigned List cannot be mistaken for a real one, and so nothing waits unnoticed for someone to be found. It also shows on the [one-day dashboard](US-13.1.1) for the day it falls on.

## Acceptance criteria

- **One visible place.** A view lists all Draft Lists that still need an anaesthetist.
- **Flagged.** Every Draft List is labelled as being prepared wherever it appears, and looks different from an assigned List.
- **On the day view.** A Draft List also appears on the one-day dashboard for its day.

## Notes

Exact placement in the Admin App is a design choice; the requirement is that admin staff can see them and are alerted they are still being prepared.
