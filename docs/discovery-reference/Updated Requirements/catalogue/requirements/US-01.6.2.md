Admins see every Draft List in the Admin App, each clearly shown as a List with no anaesthetist yet. Draft Lists show prominently in the core planning view (for example in space reserved beside the day view) as well as on their own page. Each shows its day, session, hospital and surgeon, and how long it has been waiting for an anaesthetist.

This is so an unassigned List cannot be mistaken for a real one, and so nothing waits unnoticed for someone to be found. It also shows on the [one-day dashboard](US-13.1.1) for the day it falls on.

Today unassigned requests have no home (Vanessa keeps "a pile of paper"), and neither the current display nor the RFP shows unassigned Lists, which Greg called "quite a big flaw".

## Acceptance criteria

- **One visible place.** A view lists all Draft Lists that still need an anaesthetist.
- **Flagged.** Every Draft List is labelled as unassigned wherever it appears, and looks different from an assigned List.
- **On the day view.** A Draft List also appears on the one-day dashboard for its day.
- **Sorting.** Draft lists are sorted in ascending date order.

## Notes

The layout is not designed yet. The name Draft List is kept, and admin staff seeing Draft Lists is a major feature for AA (OQ-64).
