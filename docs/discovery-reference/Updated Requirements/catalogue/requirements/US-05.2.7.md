The system holds every price excluding GST, and works GST out only when it is needed, at the bottom of the invoice.

Some Contract holders publish both figures; only the exclusive one is held.

This is because the GST rate can change, and a price held inclusive would then be wrong.

## Notes

Agreed by Donald and Greg on 7 October. Greg: "the rule for the system is that everything internally is exclusive and then the GST goes on the bottom of the invoice." Donald: "It should just be calculated when it needs to be calculated." Greg: "Absolutely, because it changes." The GST agency treatment on each document is still for AA's accountant (OQ-29).
