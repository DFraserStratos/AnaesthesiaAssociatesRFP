Where no other Contract applies to a Procedure, the Scheduling Engine defaults it to the [RVG Default Hospital Contract](US-04.1.1) for the List's hospital.

This Contract is derived automatically from the List's location, so a Procedure is never left without pricing rules to fall back on.

## Notes

The default Contract is the "no special contract" Contract: normal RVG base, time and modifier pricing, with no agreed fixed price or modifier rules. The Contract defines the [billable party](FT-11.2) (OQ-67): picking a default Contract presents a name and email field for whoever pays, so even a base Contract has a billable party (Donald). Greg disagreed in the room (a default Contract does not specify a billable party) and floated a model with no default Contract; that is unsettled and held as OQ-78. Where a fixed-rate Contract applies, the anaesthetist still records base, time and modifiers and the charge is the fixed rate; prepayment overlays either as a separate lifecycle.
