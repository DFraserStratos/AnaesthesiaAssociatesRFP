The system adds only the modifiers that cannot be removed, and shows them selected and locked:

- the [age modifier](US-03.3.8), from the patient's age
- any modifier the code's base units [already include](US-05.1.4), for example prone positioning (P1) on every neurosurgery code (H7A to H9b, supine and prone variants alike) and every spine code (S1 to S10), shown as a pill selected at 0 units that cannot be unselected, so it cannot be added again

Every other modifier is optional. The anaesthetist picks each one that applies from the RVG modifier table plus AA's own [modifiers](US-05.1.5), itemised one by one rather than as a combined total, and gives a short explanation for each one they claim.

This is because some Contracts require the itemised breakdown, not just the total units, and insurers ask why a modifier was claimed.

## Acceptance criteria

- **Locked modifiers.** Given a patient in an RVG age band, or a code whose base units include a modifier, when the anaesthetist opens the Procedure, then that modifier is already selected and cannot be removed. An included modifier shows at 0 units.
- **Nothing else pre-filled.** No other modifier is selected for the anaesthetist, whatever the patient's ASA grade or the procedure.
- **Itemised modifiers.** The anaesthetist picks each further modifier that applies, from the RVG modifier table plus AA's own, one by one rather than entering only a combined total. The choices include:
  - ASA grade
  - BMI banding
  - emergency status
  - non-standard positioning
  - awake intubation
  - pre-assessment
- **Explanation.** Given a modifier the anaesthetist claims, when they save, then it needs a short explanation.

## Technical discussion

[The draft technical design](AR-29#p7) keeps only one free-text modifier note on the Procedure, required when any modifier units are claimed, and no record per modifier ("The anaesthetist itemises modifiers in the note"). Locked modifiers, shown selected on each Procedure, imply a modifier record per Procedure. The design is a draft and may change before the catch-up build.

## Notes

Merges the former US-03.3.5 (Itemise modifiers), now Retired.

The directors, 6 October: "Some RVGs will include modifiers which can't be removed (Age)" and "All else are optional"; Donald added the modifiers a code's base units already include. The answer does not name the ASA grade: dropping the ASA seed, and any pre-fill from procedure defaults, follows from it rather than being stated, so this story moves from Proposed to Verify. The ASA grade is now chosen like any other modifier.

The 2021 RVG modifier table (pages 12 to 13) gives one value per modifier, with no typical or maximum values by body area, so the app offers that table rather than guidance by body area. The supine ('a') neurosurgery codes include P1 as well as the prone ('b') codes (OQ-94, answered 8 October); the age bands are OQ-95.

Greg floated leaving modifiers out of version one (7 October); not adopted.
