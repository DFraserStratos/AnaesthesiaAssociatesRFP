When Xero sends an invoice webhook, the engine fetches the invoice, checks it for payment, finds the matching ledger record by its [stored Xero ID](US-09.1.1), and updates it, [setting the linked ACCPAY to AUTHORISED](US-10.2.1).

This is so the payable becomes eligible for the next payables run as soon as the engine can confirm payment, without waiting on the daily poll.
