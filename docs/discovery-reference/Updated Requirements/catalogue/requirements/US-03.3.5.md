The anaesthetist itemises each modifier code that applies to a Procedure, rather than entering only a combined total. This covers:

- age extremes
- BMI banding
- emergency status
- non-standard positioning
- awake intubation
- pre-assessment

This is because some Contracts require the itemised breakdown, not just the total units.
