A Draft List is a List created with no anaesthetist. Its surgeon, hospital, day and session are always known when it is created (the hospital booking always comes first), and all four are needed to turn it into a List. Beyond the [recurring bookings](US-01.3.2) there are many extra Lists that need an anaesthetist found, and requests arrive daily, including from surgeons' rooms and secretaries.

A Draft List arises:

- when a surgeon's room needs an anaesthetist and none is assigned
- when an anaesthetist [moves a List](US-01.4.3) to the office, including when they [mark its Slot unavailable](US-01.5.5)
- when a surgeon's recurring booking lands on a Slot the anaesthetist has already marked unavailable (OQ-81)
- when an automated [reschedule](US-02.5.2) from an integration cannot move a List to its new location because of a clash

The system holds each one as a Draft List, visible to the admin team and clearly shown as unassigned, until an admin assigns it to an anaesthetist. It is never offered to anaesthetists; the office assigns it.

This is so those requests are never lost between an email and a Slot. A Draft List is different from an empty Slot (a place for a List to exist) and from a List assigned to an anaesthetist.

## Notes

The name Draft List is kept (Greg: "I like the idea of the draft list"). Seeing Draft Lists is a major feature for AA staff (OQ-64).

Whether anaesthetists would want to browse Draft Lists and pull them in themselves is a question for Ben (OQ-86); for now it is an office job (Greg).
