A Draft List is a List being prepared that is not yet assigned to any anaesthetist. Beyond the [Permanent Lists](US-01.3.2) there are many extra Lists that need an anaesthetist found, and requests arrive daily, including from surgeons' rooms and secretaries.

The system holds each one as a Draft List, visible to the admin team and clearly flagged as being prepared, until an admin assigns it to an anaesthetist.

This is so those requests are never lost between an email and a Slot. A Draft List is different from an empty Slot (a place for a List to exist) and from a List assigned to an anaesthetist.
