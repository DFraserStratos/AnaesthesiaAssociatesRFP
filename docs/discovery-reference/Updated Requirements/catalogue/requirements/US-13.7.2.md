The admin dashboard lists open warnings from the [warning routine](US-13.7.1) as a to-do list of things that need attention. An admin can clear a warning from the to-do list once it has been dealt with. Clearing is optional for a mild warning.

This is so the office has one place to see what needs doing.

## Acceptance criteria

- **Appears.** Given a new warning, when an admin opens the dashboard, then it is on the to-do list.
- **Cleared.** Given an open warning, when an admin clears it, then it leaves the to-do list.

## Notes

Where the to-do list sits on the dashboard, and whether it is part of the [one-day dashboard](US-13.1.1), is not settled: Greg spoke of "this concept of the dashboard, which is effectively the to-do list". Whether clearing a warning is recorded, and by whom, is still to check with AA.
