Admins maintain the Slot availability status table (the RFP's ListStatus) directly, each status with its own description and colour.

This means statuses can be added or renamed without any code changes.

This is the availability status, not the DRAFT, SUBMITTED and AUTHORISED [approval state](EP-07).
