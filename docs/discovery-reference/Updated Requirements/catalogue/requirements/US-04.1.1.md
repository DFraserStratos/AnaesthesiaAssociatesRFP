Admins create Contracts in one of these categories:

- RVG Default Post-paid
- RVG Default Hospital
- Hospital
- Surgeon Solo
- Surgeon Group
- Insurance

## Notes

[ACC arrangements](US-05.5.1) are Hospital or contract-holder Contracts with ACC pricing, not a separate category (RFP). There is no Pre-paid Contract category. [Prepaid](US-06.1.1) is a property of the procedure in the anaesthetist's profile, not of the Contract (Q&A #5, OQ-25). AA's answer is for this stage, so revisit if that changes.
