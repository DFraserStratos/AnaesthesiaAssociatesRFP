From their app, an anaesthetist sets each Slot's availability to one of:

- available
- available for emergency
- unavailable
- on leave

This is so the office sees the anaesthetist's availability immediately.

## Notes

[Exact status set](OQ-17) is master data and still to be confirmed (RFP lists private, public, pre-op, holiday, unavailable, free as candidates).
