Before an anaesthetist adjustment can be applied, the Procedure's [locked Contract](US-04.3.5) must allow it.

Where allowed, the system applies a percentage discount, or replaces the whole total with a fixed final price. Either way, it records the fee as it stood before the adjustment, so the full calculation is never lost.
