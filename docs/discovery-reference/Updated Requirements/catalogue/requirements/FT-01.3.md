A Slot with no List attached has no surgeon and no hospital. A List sits in one Slot and, once assigned, belongs to exactly one anaesthetist, one surgeon, one hospital, one day and one session. A [Draft List](FT-01.6) records what is known so far but has no anaesthetist yet.
