When an admin creates a hospital or a direct-billing insurer, the system creates its default Contract automatically: RVG Default Hospital for a hospital, or the Insurance default for an insurer.

This is so there is never a "no contract" branch. Every hospital and every direct-billing insurer always has a Contract to fall back on, from the moment it exists in the system.

## Notes

RFP mandates the default Contract as a one-off admin step; auto-creation is our proposal.
