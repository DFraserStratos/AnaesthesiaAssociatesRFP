The system records the units and dollars attributed to each Procedure in a Booking.

This is so that when Procedures in the same Booking sit on different Contracts, for example a hospital Contract on the primary and a [patient-direct Contract](US-11.2.1) on a cosmetic add-on, each one still carries the right amount.
