An admin creates a Draft List when a request for a List arrives before an anaesthetist is found: from a phone call, an email or PDF from a surgeon's room or secretary, or a hospital row on the [matching screen](US-02.1.2). It records what is known so far (the hospital, surgeon, day and session) and has no anaesthetist, so it does not take up any anaesthetist's Slot.

This is so the request enters the matching process and someone is made responsible for assigning it.

## Acceptance criteria

- **No anaesthetist needed.** A Draft List can be saved with no anaesthetist.
- **Takes no Slot.** Saving a Draft List does not change any anaesthetist's Slot or availability.

## Notes

What a Draft List holds, whether it can already hold Bookings, and what happens if the request is cancelled are OQ-44. Compare [manual List assignment](US-01.3.3), which assigns a surgeon and hospital to a Slot that already belongs to an anaesthetist.
