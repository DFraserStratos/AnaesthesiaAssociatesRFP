AA staff create a Draft List when a surgeon's room needs an anaesthetist and none is assigned, for example from a phone call, or an email or PDF from a surgeon's room or secretary. The hospital, surgeon, day and session are required. It has no anaesthetist, so it does not take up any anaesthetist's Slot.

Bookings can be added to it before an anaesthetist is assigned.

This is so the request enters the matching process and someone is made responsible for assigning it.

## Acceptance criteria

- **No anaesthetist needed.** A Draft List can be saved with no anaesthetist.
- **Required.** A Draft List cannot be saved without its hospital, surgeon, day and session.
- **Bookings allowed.** Bookings can be added to a Draft List before it is assigned.
- **Takes no Slot.** Saving a Draft List does not change any anaesthetist's Slot or availability.

## Notes
