The Scheduling Engine will create exactly two Slots for every active anaesthetist in the system on a daily basis, four months in advance: an AM and a PM Slot. It does this even when no List is attached and nothing is booked.

Each new Slot starts as free. Slots are created even when the anaesthetist is free or unavailable, so the views can show every anaesthetist.

This is so the Admin team always have somewhere to make bookings, and the calendar shows a complete picture with no gaps.

## Technical discussion

Whether every Slot is stored or empty ones are inferred is left to implementation, provided every known anaesthetist's Slot status shows, and Lists with no anaesthetist ([Draft Lists](FT-01.6)) show too (OQ-64).

## Notes

About 85 x 120 x 2 = 20,000 Slot records at current roster size.
