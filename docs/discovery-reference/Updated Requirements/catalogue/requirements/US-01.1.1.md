The Scheduling Engine will create exactly two Lists for every active anaesthetist in the system on a daily basis, four months in advance: an AM and a PM List. It does this even when they hold no bookings.

This is so the Admin team always have somewhere to make bookings, and the calendar shows a complete picture with no gaps.

## Notes

About 85 x 120 x 2 = 20,000 List records at current roster size.
