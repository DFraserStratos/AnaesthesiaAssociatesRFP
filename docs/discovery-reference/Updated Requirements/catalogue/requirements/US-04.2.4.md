Admins enter the individual lines of a fixed fee schedule, for Contracts priced this way.

Each line carries the contract holder's own code and description, and its price both excluding and including GST. A line can also carry:

- an optional mapping to an RVG code
- an optional time band
- a flag marking it as an add-on
- a quantity rule

The optional RVG mapping matters because it lets BTM still be recorded against an RVG code even when the price itself comes from the fixed fee schedule line.

## Notes

Real examples: SXAP AP codes, CES HNZ codes, ACC OPT codes, Merivale set fees, vitrectomy time bands, GA add-on fees, liposuction per area.
