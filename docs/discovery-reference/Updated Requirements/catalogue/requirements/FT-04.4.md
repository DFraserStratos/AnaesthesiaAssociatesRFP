Every hospital and every direct-billing insurer needs a default Contract already in place. This closes off any path where a Procedure done at a hospital, or billed to an insurer, has no Contract to price it against.

Every procedure on the [master procedure list](US-05.1.6) also has one default RVG Contract, which holds its base units (OQ-62), plus any further named RVG-style Contracts AA adds.
