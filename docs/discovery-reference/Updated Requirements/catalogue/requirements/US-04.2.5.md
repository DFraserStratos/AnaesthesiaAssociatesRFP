Admins set how a Contract prices additional procedures in the same anaesthetic episode, alongside the primary one.

The options are:

- [the RVG default rule](US-05.3.1): base units apply to the primary procedure only, time units apply to every procedure, and modifier units are split once their total exceeds four
- a percentage of the second procedure's own code, for example 50%
- a fixed add-on fee
- not billable at all

This lets a Contract replace the standard multi-procedure rule where a real fee schedule, such as SXAP or CES, prices additional procedures differently.

## Notes

A combination of procedures is priced by a [combination Contract](US-04.2.11) set against each parent procedure. Greg's "operation" level (several procedures under one Contract, with time and modifiers on the operation) was not adopted; the simpler model is to be tried in the next prototype.
