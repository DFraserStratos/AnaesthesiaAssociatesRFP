When a Booking is created or matched to a patient who has an invoice unpaid for longer than the alert threshold, the system alerts the admin. The threshold starts at 90 days and admins can change it (to be confirmed with Ben, OQ-41).

This is so AA can follow up on the outstanding balance before the next procedure goes ahead.

Patients are allowed 90 days to pay and AA raises around 100 invoices a day, so a younger unpaid invoice is not yet a problem. Some patients come back with invoices six months to two years old.

## Acceptance criteria

- Given a patient with an invoice that has been unpaid longer than the threshold (start 90 days; what it counts from is OQ-41), when a Booking is created or matched to them, then the admin is alerted.
- Given a patient whose only unpaid invoice is 30 days old, when a Booking is created or matched, then no alert is raised.
- Given an admin changes the threshold, then the new value applies to the next Booking check.
