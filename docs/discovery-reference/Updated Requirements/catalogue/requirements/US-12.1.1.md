As an anaesthetist, I set my own dollar value per RVG unit.

## Technical discussion

Proposed in our RFP response: when a List is finalised for billing (AUTHORISED), the anaesthetist's rate and unit value, contract terms, party details and other applicable details are copied into the billing record, so a later change to the unit value cannot rewrite an issued invoice.
