The anaesthetist picks the Procedure's [RVG code](US-05.1.1) from a curated, searchable dropdown, [grouped by anatomical site and other groupings](US-05.1.3). Picking a code seeds its base units automatically, and where the code carries a unit range rather than one fixed number, the anaesthetist then chooses the exact value within it.

This is because the range of procedures actually performed is too varied for the system to derive the right code, or the right figure within a ranged code, on its own. The anaesthetist's own selection and professional judgement, from a curated list, is the reliable source.

## Acceptance criteria

- **RVG code.** The anaesthetist picks the Procedure's RVG code from a curated, searchable dropdown, grouped by anatomical site and other groupings. Picking a code seeds its base units automatically.
- **Ranged base code.** When the RVG code selected has a unit range, for example 6 to 8 rather than one fixed number, the anaesthetist chooses the exact base unit value within that range.
