As an admin, I mark the List AUTHORISED, which locks its Bookings, Procedures and selected Contract versions and passes the whole List to the Billing/Invoice Engine.

## Technical discussion

Proposed in our RFP response:

- Snapshot at lock: when the List reaches AUTHORISED, the engine copies all reference data the calculation depended on (contract terms, rates, RVG values, anaesthetist unit value, party details) into the billing record, so the invoice stays tied to what was true when it was raised.
- Elsewhere, hospitals, surgeons, statuses, rates and similar reference data are referenced by identity rather than copied; freezing at authorisation is the single exception. The exact fields are to be determined in discovery.
