When the hospital's list differs from what's in the app, the anaesthetist can add the missing Booking directly to their List, either by entering it manually or by photographing the physical hospital or surgeon booking card.

From a photo, the system reads the image and pre-fills the Booking, so the anaesthetist only needs to check it and confirm, rather than type everything in by hand.

This Booking flows back to the Scheduling Engine like any other, whichever way it was entered.

## Acceptance criteria

- **Photo capture.** The anaesthetist can instead photograph the physical hospital or surgeon booking card; the system reads the photo and pre-fills the Booking, so they only need to check it and confirm rather than type everything in by hand.

## Notes

Merges the former US-02.4.2 (Photo capture of the physical card), now Retired.

In theatre the anaesthetist must still be able to create a Booking on the fly, even if surgeons' rooms are one day able to add Lists themselves (a wish raised in the meeting, not a decision).
