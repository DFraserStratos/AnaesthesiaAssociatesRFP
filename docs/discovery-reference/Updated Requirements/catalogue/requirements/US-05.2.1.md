The system prices RVG units at each [anaesthetist's own dollar value per unit](US-12.1.1) by default, never a price list shared across anaesthetists.

This default is a Commerce Act requirement: anaesthetists cannot collectively agree on pricing.

## Acceptance criteria

- **Contract rate or discount.** When a Procedure's Contract sets an [agreed rate or a discount](US-04.2.2), the system applies that instead of the anaesthetist's own unit value.

## Notes

Merges the former US-05.2.4 (Contract rate or discount), now Retired.
