For each row imported from a hospital download, the admin decides what happens to it. They can:

- match it to an existing List and Booking
- create a new Booking on an existing List
- create a new List in an anaesthetist's Slot, or a [Draft List](US-01.6.1) when nobody is assigned yet
- reject it

This is so the schedule always reflects the hospital's data, whichever of these a row needs.
