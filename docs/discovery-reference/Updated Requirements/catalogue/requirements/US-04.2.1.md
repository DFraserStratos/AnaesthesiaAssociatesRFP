Admins define who holds each Contract, meaning who is invoiced under it: a hospital, a surgeon or surgeon group, an insurer, or the Booking's own [billable party](FT-11.2).

Admins also set where the Contract applies, using filters on any of:

- hospitals
- surgeons
- insurers
- RVG codes or groups
- funding source
- specific anaesthetists

By default, the anaesthetists filter is empty and the Contract applies across the whole organisation. Admins can narrow it to specific anaesthetists instead, which is how an individual anaesthetist's own arrangement gets set up as its own Contract, without affecting the organisational one.

This scope is what the system uses to [narrow the list of Contracts offered](US-04.3.2) when one is chosen for a Procedure, so admins only see the Contracts relevant to that hospital, surgeon, insurer or funding source.

## Acceptance criteria

- **Organisational and individual scope.** The anaesthetists filter defaults to empty, meaning the Contract applies to the whole organisation. Admins can narrow it to specific anaesthetists instead, so an individual anaesthetist's own arrangement can be set up as its own Contract later, without affecting the organisational one.
