Admins define who holds each Contract: a hospital, a surgeon or surgeon group, an insurer, or the Booking's own [billable party](FT-11.2). The Contract always defines the billable party, and there can be as many Contracts as AA needs (OQ-67).

Admins also set where the Contract applies, using filters on any of:

- hospitals
- procedures from the [master procedure list](US-05.1.6) (a Contract sits against one or more procedures)
- surgeons
- insurers
- RVG codes or groups
- funding source
- specific anaesthetists

By default, the anaesthetists filter is empty and the Contract applies across the whole organisation. Admins can narrow it to specific anaesthetists instead, which is how an individual anaesthetist's own arrangement gets set up as its own Contract, without affecting the organisational one.

This scope is what the system uses to [narrow the list of Contracts offered](US-04.3.2) when one is chosen for a Procedure, so admins only see the Contracts relevant to that procedure and hospital (and possibly the surgeon, not settled).

## Acceptance criteria

- **Organisational and individual scope.** The anaesthetists filter defaults to empty, meaning the Contract applies to the whole organisation. Admins can narrow it to specific anaesthetists instead, so an individual anaesthetist's own arrangement can be set up as its own Contract later, without affecting the organisational one.

## Notes

Merges the former US-04.2.9 (Organisational and individual Contracts), now Retired. Both were Proposed, so status carries over unchanged.

Every hospital gets a default RVG Contract plus its fixed and other Contracts. RVG variants with different base units are Contracts too. Many insurance jobs are plain RVG, just paid by the insurer.

The insurer and funding source filters no longer narrow the picker, because neither the Patient nor the Booking holds an insurer or funding source (OQ-55). They stay as scope filters: OQ-67 settled that the Contract defines the billable party, but not whether a Contract belongs to the hospital or to the funding source.

Greg floated a different model in the 2026-10-02 meeting (no default Contract, the hospital holding every Contract, RVG pricing where there is none). It is unsettled and held as OQ-78, not in this requirement.
