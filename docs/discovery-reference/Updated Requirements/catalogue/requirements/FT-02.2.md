Surgeons' rooms email PDF lists of their bookings. The system reads them, lets AA staff correct the extracted details, and ingests them as Bookings.

This is the smaller pathway today: the hospital download (FT-02.1) carries more bookings (OQ-34), so this feature ranks second.

## Notes

PDF ingest is still needed after the hospitals' HL7 v2 or FHIR feeds arrive: the hospital download is not comprehensive, so the theatre list is still needed for the insurer or Contract.

Tentative (Donald): the first release may need [hospital download](FT-02.1) matching like the current system before PDF ingest. The hospital download's formats and fields are OQ-13.
