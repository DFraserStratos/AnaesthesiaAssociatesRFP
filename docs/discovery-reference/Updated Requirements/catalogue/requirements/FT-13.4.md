Admin maintains all reference data.

## Technical discussion

Proposed in our RFP response: master and reference data is migrated at cutover. The data to migrate is identified with AA (for example users and roles, anaesthetists, hospitals and sites, and contract and billing reference data). Scripts automatically extract, transform and load (ETL) it, all data is checked and validated ahead of time, and the extract is re-run if needed to pick up data added to the old system in the interim.
