When a returning patient's [Xero contact has been archived](US-09.3.3), the engine unarchives the contact and then invoices against it, so no duplicate contact is created for the same patient.

## Notes

Answered (OQ-10): always unarchive first, to prevent duplicate contacts. Greg has little experience of archiving; his understanding is that it exists because Xero does not want more than about 10,000 active contacts ("theoretically") (Notes 2026-10-01 #5). Whether Xero's API needs a separate unarchive call is still to check in the sandbox (OQ-10).
