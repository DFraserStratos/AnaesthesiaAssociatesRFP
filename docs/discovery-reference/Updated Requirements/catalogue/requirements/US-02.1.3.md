When an imported row matches an existing Booking, the admin sees the field-level differences, such as time, patient or procedure, before applying them.

This is so admins can check exactly what a hospital update changes before it reaches the schedule.

## Notes

An update to an already matched Booking still goes through this manual approval, showing the differences; for a row with no match, the admin effectively accepts it as a new record (Greg). Donald: automating updates after the first match "wouldn't take too much", but this manual step stays in for now.
