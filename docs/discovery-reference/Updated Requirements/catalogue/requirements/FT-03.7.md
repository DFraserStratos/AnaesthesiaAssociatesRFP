An event is anything recorded against a Procedure after it is set up: a pre-op or post-op time recording or fixed fee, an [additional invoice](US-08.6.3) or a credit. "Event" is the one name for all of them. Each event is its own element attached to the original Procedure, not a Procedure added to the Booking, and all of a Procedure's events are visible on it.

- Mostly the anaesthetist adds events; the admin team can too, when someone rings and asks them to record one.
- Each event has a tick box for whether it will be invoiced, so an event can be recorded without being billed.
- A billed event is its own line item, bundled with the Procedure's invoice if possible, otherwise invoiced in the next run, through the same review step as everything else.

This is so anaesthetists can add post-care themselves instead of ringing or emailing the office. It covers:

- pain management after the procedure, the common case
- an [ACC pre-op assessment](US-05.5.2), a fixed-fee service recorded against the real Procedure
