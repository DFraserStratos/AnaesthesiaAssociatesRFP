Once the office has finalised a List and sent it through to invoicing, the List drops off the anaesthetist's main view and its invoices show as lines in their [outstanding balances](US-12.2.1). The anaesthetist can still find the List afterwards in an archive or search.

This is so the main view holds the work still in progress, while the anaesthetist can still go back to finished work when an invoice is queried months later.
