The Scheduling Engine requires every Booking that has Procedures to have exactly one of them marked primary. Base units, and modifiers under the usual rule, anchor to this primary Procedure.

This is so a Booking with several Procedures in the same anaesthetic episode still has one clear place for the units that must never be charged twice.
