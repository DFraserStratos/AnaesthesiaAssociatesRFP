Before an anaesthetist can submit a List as 'Completed', every Booking within the List must be [marked as complete](US-03.6.1).

Once a List is submitted, it gains the status SUBMITTED.

While any Booking is still incomplete, the system will not let the anaesthetist submit the List. It shows them [what is still missing](US-03.6.2), so they know what to finish before they can submit.

## Acceptance criteria

- **Incomplete List.** The system will not let an anaesthetist submit a List while any of its Bookings is incomplete. When submission is blocked, it shows the anaesthetist [what is still missing](US-03.6.2), so they know what to finish before they can submit.

## Notes
