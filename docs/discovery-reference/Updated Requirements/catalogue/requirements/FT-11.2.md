Each Procedure's Contract defines who pays for it (the billable party) and where the invoice is sent. Picking a default Contract asks for the payer's name and email, so even a default Contract has a billable party.

## Notes

The billable party is always defined by the [Contract](US-04.2.1), with as many Contracts as AA needs (OQ-55, OQ-67). There is no separate per-Booking billable party.

Greg floated a different model (no default Contract; the hospital holding the Contract always pays, with RVG where there is no Contract). It is not settled and is not part of these requirements; it is held as OQ-78.
