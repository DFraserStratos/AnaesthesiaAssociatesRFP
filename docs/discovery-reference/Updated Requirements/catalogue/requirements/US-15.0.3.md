As any user, data is entered once and is current everywhere it appears.

## Technical discussion

Proposed in our RFP response: hospitals, surgeons, statuses, rates and similar reference data are referenced into the schedule by identity, not copied into it, so a change made once is reflected everywhere. The one deliberate exception is the billing model, where reference data is frozen at authorisation so an issued invoice cannot be rewritten by later drift. Exactly which fields are frozen is to be determined in discovery.
