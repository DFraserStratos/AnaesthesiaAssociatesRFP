Admins load the modifier list as master data. It is AA's own list, made of:

- the [RVG modifier table](AR-16#p12): 30 codes on RVG pages 12 to 13, covering pre-assessment, age, ASA and emergency, BMI, awake intubation, P1 non-supine positioning, vascular monitoring, echo, recovery, additional anaesthetist, post-operative cover and nerve catheters
- the modifiers AA uses that are not in the RVG (Vanessa's list)

Each modifier holds its units as the RVG prints them. Some values are not one number, for example "2 + Time", "4-6", "1 per call" or a cap, so a modifier's value needs more than a single figure. Some codes repeat across RVG tables (A1, A2 and P1 are also base codes), so a code alone is not a key.

Only the [age modifiers](US-03.3.8) apply automatically, from the patient's age. A modifier already [included in a code's base units](US-05.1.4) shows locked at 0. All others are [the anaesthetist's choice](US-03.3.4).

This is so the anaesthetist picks from one complete list, and the units each modifier adds are the same for everyone.

## Notes

The RVG transcription is `Data files/NZSA RVG 2021 modifiers.md`, made 2026-10-07 from the PDF; spot-check it against the PDF before relying on it. The 2021 edition has no page 12 table of typical and maximum modifier values by body area: pages 12 to 13 give one flat value per modifier, so the requirement refers to the RVG modifier table. The guide's sentence about page 12 guidance by body area needs correcting. Also open in the file: frailty is named with no code or units; the RVG's worked example 2 gives BMI 37 two units where the table gives one; and the RVG has no after-hours, weekend or public-holiday loading, so any AA uses comes from Vanessa's list.

Directors, 6 October: "Some RVGs will include modifiers which can't be removed (Age)" and "All else are optional". The age lock is AA's rule: the RVG leaves all modifying units "at the discretion of the individual anaesthetist". The age bands and stacking are OQ-95. The directors did not name the ASA grade: that the earlier ASA pre-fill is dropped follows from "All else are optional" and is still to confirm with AA.

Status Verify: dropping both the ASA pre-fill and the pre-fill of a procedure's default modifiers is implied by the directors' "All else are optional", not named by them. Confirm with AA that no modifier other than age (and those included in base units) is pre-filled.

Vanessa holds the fuller list of modifiers AA uses that are not in the RVG. Position loadings such as sitting (beach-chair) and prone are modifiers, not base units.
