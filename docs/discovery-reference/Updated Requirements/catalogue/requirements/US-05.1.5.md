Admins load the modifier code set as master data, with each code's unit value.

It is AA's own distinct list, generated partly from the NZSA guide and partly from modifiers AA creates.

## Notes

The set is to be extended from a fuller modifier list with units that Vanessa holds; the simple guide does not list all of them. Position loadings such as sitting (beach-chair) and prone are modifiers, not base units.
