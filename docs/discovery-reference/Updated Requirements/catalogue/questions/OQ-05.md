If one Booking fails in the Billing/Invoice Engine, does the whole List wait or do the other Bookings invoice?

## Answer

There's no reason a list needs to fail. when a booking can pass.

But a booking could fail if one of the billable parties on one or many of the procedures fails.
In this case, the full booking would fail, an fall back to a manual fix by AA admin staff.
