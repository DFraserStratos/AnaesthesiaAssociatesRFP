OQ-70: when a prepaid Booking moves to another anaesthetist, the payable half of the draft pair is updated to the new anaesthetist. Greg: "we'll have to amend the payable pair because the trust account in Xero always has to balance", which raises "a question about when in the life cycle we should create" it. Is the pair created when the prepayment invoice is generated, when an admin approves it, or when the money is received? And at which points (a move, a cancellation, the final invoice) is it amended?

Recommendation: create the pair when the prepayment invoice is generated, as the catalogue already says, and amend only the payable on any move before the procedure.

Shown as not yet decided on [the billing and invoice flow](AR-24#prepayment-pair-undecided).

Update 2026-10-07: not answered. Donald's expansion of the directors' answer says that when a prepaid procedure moves to another anaesthetist, "the system should not try and have any logic to detect any of these flows that would re-trigger any sort of calculations for invoices." Whether the payable is still updated on a move under that is not said. (See "Notes 2026-10-06 · AA directors meeting #10")
