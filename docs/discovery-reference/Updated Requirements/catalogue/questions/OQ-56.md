OQ-32 settled that the anaesthetist may set base units on a [ranged RVG code](US-03.3.1) as they see fit, so the system no longer blocks an entry outside the published range. It did not settle what happens instead. When an anaesthetist enters base units outside the code's published range, should the system accept it silently, or raise a flag for the office to check at review?

Recommendation: accept it, and raise an office review flag. This is the catch-up plan's build default (reverse finding RV-04, Phase 19) if no answer comes in.

## Answer

An anaesthetist can override as they see fit.

But a warning should be presented to the AA admin staff.
