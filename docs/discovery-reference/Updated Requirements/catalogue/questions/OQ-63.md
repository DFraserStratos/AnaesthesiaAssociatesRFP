The anaesthetist can add pre-op and post-op events (a time or a fixed fee, no other modifiers) to a Procedure. Not settled: (1) is an event a Procedure added to the Booking (Greg's lean) or its own element attached to the original Procedure (Donald)? (2) on an invoice is it a line item or a procedure? (3) its short name; (4) does it go through admin approval before invoicing, when an admin's additional invoice needs none? (5) what "may or may not be billable" means in practice.

Recommendation: its own element attached to the original Procedure, shown as its own invoice line, approved by the office before invoicing.

## Answer

1. Donald's right. its own element attached to the original Procedure
2. Line item
3. All of these are just called events. And in the UI on a procedure, all events will be visable. Pre op, post op, additional invoices, whatever.
4. All events are bundled with the procedure invoice if possable. Otherwise, next run. And yes, all have the same standard review step, single process for everything.
5. These events have a tick box to mark if they will be invoiced. So these events can still be recorded, but not invoiced.
