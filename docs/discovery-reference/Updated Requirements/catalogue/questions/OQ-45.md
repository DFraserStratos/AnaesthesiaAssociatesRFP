An [additional invoice](US-08.6.3) is attached to a Procedure and to a Contract on that Procedure, and the admin can set its lines freely. Does it follow the Contract's locked version and pricing basis (a fixed fee schedule may have no line for a post-op review), or is it priced from time units and modifiers at the anaesthetist's own unit value unless the admin overrides it with a reason? Can it be billed to a different billable party than the original (needed for splits)?

Recommendation: default to RVG time units and modifiers at the anaesthetist's own unit value, with the admin free to override the amount and billable party, every override audited.

## Answer

This is simply a free form function to create an invoice.

Desc, Qnt, $

Not to be confused with previous chats about splitting a contract's invoice.

Transcript adds: Greg sees it as an admin function that solves the awkward cases. It is also how a combined procedure is broken out when a billable party (for example an insurer) wants separate invoices. Not clear from the transcript: whether "Desc" means description or discount, and whether it can go to a different billable party. See Notes 2026-10-01 · AA meeting with Greg #21 #27 #61.
