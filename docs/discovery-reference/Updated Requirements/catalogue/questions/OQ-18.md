Fixed fee schedules use the holder's own codes (SXAP AP codes, HNZ codes, ACC OPT codes). Should the anaesthetist select the holder code directly when such a Contract applies, with an optional RVG mapping for BTM recording, or always pick an RVG code and have the system map it?

## Answer

We will have a master procedure list and a master contract list. 
If we need to use a contract from one of these parties, we will store their codes for reference.

But the pair of Procedure & contract means that there could be both an RVG code, and a paritie's code

Transcript adds: Contracts may keep the holder's own codes as reference codes, and they are searchable (typing "8942" filters to that Contract). AA will also need its own unique identifier for every Contract, a coding scheme still to be worked out. Donald has doubts about the model; it is marked answered for now and built into the prototype, to be validated later. See Notes 2026-10-01 · AA meeting with Greg #10.
