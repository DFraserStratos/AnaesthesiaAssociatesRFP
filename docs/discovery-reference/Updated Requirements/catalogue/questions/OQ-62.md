The OQ-06 board answer puts base units on the RVG code master (a Contract may override). The meeting agreed the opposite: base units live on a master procedure list, each procedure with its own base units ideally derived from an RVG code, with default and hospital Contracts taking them from it, and Donald proposed dropping "RVG" from its name. Which is it? Also: the user picks from "the procedure list grouped by RVG body headings" (OQ-53); is that list of operation names (the master procedure list) or of RVG codes?

Recommendation: the master procedure list, as agreed in the room, with the RVG code master keeping the guide's own values; Vanessa's standard procedure list is the input.

## Answer

As I see it. 

The Master RVG procedure list hold RVG codes, and each procedure has one or two default RVG contracts which holds the base units and all other settings.

The meeting adds: in the room Donald described "a master list of procedures, which has the groupings of body parts", which "may reference RVG codes", and "really the base units live in the contracts": for every procedure a base contract, "understood to be the standard RVG recommendation for base units", maintained by hand after an initial spreadsheet import. The transcript says one base contract per procedure; the answer says one or two. Greg asked how a (rare) RVG change flows through, and floated making contracts children of a master code so a change routes to every contract with that parent (Donald: "it could have multiple parents"; Greg: "That's all right if we do that. All those thousands, it's becoming really too many relationships"); not settled. (See Notes 2026-10-02 · AA meeting with Greg #3 #22 #40)
