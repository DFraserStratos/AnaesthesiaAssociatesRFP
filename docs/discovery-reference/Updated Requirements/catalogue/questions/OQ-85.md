Agreed: an anaesthetist can move a single Booking as well as a whole List. Not defined: (1) how they find the receiving anaesthetist (Donald: the app could not show every List, "you'd kind of want it to just have a search box to search by an anaesthetist"); (2) where the Booking lands when the receiver has no List in that Slot, for example a List created on the fly with that one Booking, and whether others may then add Bookings to it (Greg's favour case); (3) whether the move posts to the shared notification pool and offers the update email, as a List move does; (4) whether the blacklist warning applies.

Recommendation: search by anaesthetist; only receivers whose Slot is available are offered; a List is created in the receiver's Slot when none exists; the move notifies and warns as a List move does.
