OQ-67 was answered on the board: the Contract always defines the billable party, with as many Contracts as AA needs. In the room Greg did not settle it and floated a different model, questioning "the assumption that we should create a default contract". Today staff pick "RVG" as a contract type meaning standard pricing. With no default Contract per hospital, "the billable party is always the hospital that holds the contract and there is no contract with individuals", and RVG pricing applies where there is no Contract. This sits against the board answer, the default Contract that asks for the payer's name and email, the default RVG Contracts per procedure (OQ-62) and prepayments always billed to a person (OQ-73). Greg is to think through what a Contract is and come back. Is there a default Contract, and who is the billable party when no specific Contract applies?

Recommendation: keep the catalogue's model (the Contract defines the billable party; default RVG Contracts ask for the payer's name and email) until Greg brings his Contract design, then revisit.
