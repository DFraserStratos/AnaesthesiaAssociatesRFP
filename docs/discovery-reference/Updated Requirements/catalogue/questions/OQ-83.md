Only an account login for the anaesthetists' PWA is assumed (Greg: "what's the experience going to be when the anaesthetist brings up the app on the phone?"). Not settled: (1) which platforms are supported, a PWA first and a native app later or not; (2) biometrics: a native app can use Face ID or a fingerprint, a standard PWA probably cannot; (3) MFA for anaesthetists (the RFP response recommends it enforced for admin accounts); (4) single sign-on, for example with a Google account (higher Auth0 tiers; the RFP response proposed Google and Apple social login on mobile); (5) the identity provider, Auth0 (Stratos' default) or Microsoft Entra External ID (the RFP response).

Recommendation: define the deployable platforms first, then the experience (Donald: "first we need to define this type of deployable platform").
