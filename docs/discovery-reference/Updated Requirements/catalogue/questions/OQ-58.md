Two requirements disagree. [Trigger and inputs](FT-08.1) says the Billing/Invoice Engine takes no action on a List before it is AUTHORISED. [Raise the prepayment invoice](US-06.3.1) has the engine raise the prepayment invoice as soon as the estimate is set at booking setup. Does the engine raise the prepayment invoice automatically, or does the office raise it (prompted on the Booking)?

Recommendation: the engine raises it when the estimate is set, written into FT-08.1 as a named exception. This is the catch-up plan's build default (Phase 27) if no answer comes in.
