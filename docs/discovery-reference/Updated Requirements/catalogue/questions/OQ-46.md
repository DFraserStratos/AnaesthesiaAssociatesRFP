Vanessa's main need is telling hospitals when the anaesthetist on a List changes (cover). That is a change to a List (US-01.4.1), not to a Booking. Recommendation: offer the button after any saved change to a Booking and after a List reassignment; To is the hospital contact for cover changes and the surgeon's room for Booking changes, editable by the admin.
