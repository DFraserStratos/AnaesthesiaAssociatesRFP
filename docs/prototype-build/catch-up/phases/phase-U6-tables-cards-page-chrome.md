## Goal

The page skeleton becomes one set of parts. Tables share one header cell, body cell, group row and shell (`src/shared/table/`), with a density context so web stays comfortable and admin stays compact; every admin table takes the Admin Review mockup header and an e1 shell (question 19). Clickable rows share one row and one keyboard handle, so the Draft Lists table opens its drawer by keyboard. One `Card` replaces the web `Panel`, the admin `ProfileCard`, the right rail's cards and the stable admin section cards, and the mobile radius-16 cards go to 14 (question 20). One `Eyebrow` (11/600, question 23), one `PageHeader`, one `StatTile` and one `DefRow` in a `DefList` replace the hand-typed copies. Every session block draws its fill through `blockFill`, which fixes the flat hatched session on the web week strip. No redesign: default props keep today's look, and the only visible changes are the ones listed in drift check step 5.
