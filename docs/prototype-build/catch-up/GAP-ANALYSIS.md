## Summary

### Headline

The prototype is still the July RFP model. The EP-01 canvas, billing-run isolation, audit, NHI validation, per-anaesthetist unit value, GST-exclusive maths and the 15a warning registry match the catalogue. Almost everything else sits one design generation behind. Across the ~190 graded items there are only a handful of Matches (US-05.2.1, 05.2.6, 05.2.7, 05.3.5, 05.4.2, US-11.1.1, FT-03.2) and a large share of Contradicts: not missing features but the old design standing where a new one is required. The gap is structural, not cosmetic. Five foundations (Slot/Draft List, Contract/Procedure model, ledger payable, prepayment model, intake matching) must be rebuilt before most screens can be touched. Verified counts: 46 data-model deltas (DM-13 to DM-38, none refuted) and 34 reverse-check findings (RV-nn). Rough total: well over 40 XL/L blocks, but they collapse into about 8 shared builds (below). Do not sum the item sizes: many items share one build.

### Demo-trigger buttons

The owner's pattern: screen-contextual buttons in the top control area, shown only on the screen where the effect is visible. About 38 graded items carry a trigger note; roughly 20 need a genuinely new control, the rest reuse existing ones (clock advance, fire-hospital-message, S4 jump, Payment received, Run payables) or need only seed changes. Main clusters:

- **Hospital intake:** "Receive hospital download" / "Sync from hospitals" on the matching screen (FT-02.1, US-02.1.1, 02.1.3, 02.1.5), plus a hospital list arriving with an NHI (US-11.1.5).
- **Draft Lists:** "Surgeon room request", "Recurring booking hits an unavailable day", "Anaesthetist moves a List (6am)" (FT-01.6, FT-13.8, US-13.8.1, 13.8.2).
- **Prepayment and trust:** release payable, cancel and refund, approve with letter (FT-06.5, US-06.3.1, 06.3.6, 06.5.1, 06.5.2, 06.5.4).
- **Credit and additional invoices:** credit-and-rebill, additional invoice, split, credit note (US-08.6.2 to 08.6.5); these are real product actions on the invoice or Booking page, not control-panel items, with Xero view showing the pair.
- **Payment cycle:** close week, flag anomaly, build schedule, approve (FT-10.2, US-10.2.1, 10.2.6, 10.2.7), placed on the Billing monitor only. demoTriggers.test.ts:54 forbids a 'payables' trigger label.
- **Warnings and problem lists:** make-child-payer, hospital list with NHI (US-11.2.4, 11.1.4, FT-13.7). Several others are "seed it" (US-07.2.2, US-03.1.8).

[EP-04](../../../requirements-board/requirements/stories/EP-04.md) · epic status Confirmed · 8 Contradicts, 11 Partial, 2 Missing

No Matches in this epic. Existing demo controls usable: clock advance (new version taking effect), fire-hospital-message (feed Booking arriving without a Contract), S5 scenario jump.
