(3) Hourly rate x time billing line, permitsIndividualArrangement flag and INDIVIDUAL_ARRANGEMENT_MESSAGE should be reworked into a Contract defined unit rate (US-05.2.6, OQ-89, shared with US-04.2.2 and US-03.3.6). Modifier list should gain VM1, TTE, PACU, EAA, POC, NC per domain-model.md. (6) Time-unit tiers should become data (US-05.2.2) and the stale 'assumption' copy removed (UnitsCard caption, DemoControlPanel callout, timeUnits.ts comment). (7) ACC pre-op (US-05.5.2) depends on events FT-03.7 / US-03.7.1 (not built). Verifier corrections: FT-05.2 size None to S (Partial cannot be size None); US-05.1.1 Partial to Contradicts (base units still priced from the RVG master, Absorbs column). Items 05.2.1, 05.2.5, 05.3.5, 05.4.2 confirmed Matches; minor notes: Type 3 silently falls back to BTM when no schedule row matches (revisit with US-04.2.4/OQ-89). No demo-trigger buttons needed for this epic (all behaviour is user-driven in master data and capture screens).
