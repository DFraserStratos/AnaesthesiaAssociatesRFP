## EP-07 · List approval workflow · Contradicts

[EP-07](../../../../requirements-board/requirements/stories/EP-07.md) · [board](http://localhost:5180/#/board?item=EP-07) · status Confirmed · surfaces: domain, store, seed, admin, mobile, web, pwa, demo-guide · confidence high

- **Requirement:** Four List states: DRAFT (Draft List, no anaesthetist), ACTIVE (all five of pairing; anaesthetist edits and submits), SUBMITTED (anaesthetist edit access removed, office review), AUTHORISED (locks Bookings, Procedures, selected Contracts; hands to billing). An ACTIVE List moved/withdrawn/clashed becomes a Draft List again.
- **Prototype today:** ListState = DRAFT \| SUBMITTED \| AUTHORISED (types.ts:46). DRAFT means 'anaesthetist-editable' and is set on every generated canvas List incl. free/holiday/unavailable slots (canvas.ts:108). submitList (DRAFT to SUBMITTED, completion-gated, lifecycle.ts:210) and authoriseList (office only, SUBMITTED only, emits listAuthorised to billing run, :277) work; edit rights follow state; AUTHORISED locks Bookings. Reassign/move leave free slots, not Draft Lists.
- **Missing or wrong:**
  - No ACTIVE state; the old DRAFT is the new ACTIVE (name collision with the new DRAFT meaning)
  - No Draft List: List.anaesthetistId is mandatory, no unassigned List entity (FT-01.6 dependency)
  - No ACTIVE to Draft List transition on move/withdraw/reschedule clash
  - UI prints raw 'DRAFT': admin ListDrawer header (ListDrawer.tsx:51), RolesInfo copy 'while the List is DRAFT' (RolesInfo.tsx:24,34), DemoData state filter
  - ACTIVE not derived from the five-part pairing (free/holiday/unavailable slots and private Lists with no surgeon, util.ts:111 'Surgeon not yet assigned', all carry DRAFT)
- **Evidence:** `aa-prototype/src/domain/types.ts:46`, `aa-prototype/src/store/lifecycle.ts:210-290`, `aa-prototype/src/domain/seed/canvas.ts:108`, `aa-prototype/src/apps/admin/components/ListDrawer.tsx:51`, `aa-prototype/src/apps/admin/RolesInfo.tsx:24-34`, `aa-prototype/src/apps/mobile/screens/ListDetailScreen.tsx:103`, `searched: 'ACTIVE' as list state, Draft List, unassigned in src -> none (only SW worker state and a routes comment)`

- **Missing or wrong:**
