## US-01.4.7 · Anaesthetist moves a single Booking · Missing

- **Requirement:** Anaesthetist moves one Booking from their List to a colleague free in that Slot (scroll or typed-name search); creates a new List in the receiver's Slot; never into an existing List; unavailable colleagues not offered; optional admin notice or update email; no pairing warning.

- **Demo trigger:** Add a 'Move this Booking to a colleague' action on the Booking detail in mobile and web (no demo button needed; it is a real anaesthetist action). Add a demo trigger 'Colleague moves one of my Bookings into their session' to show the receiver side.
