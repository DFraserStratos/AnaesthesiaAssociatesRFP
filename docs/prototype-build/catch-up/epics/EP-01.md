Part of the [gap analysis](../GAP-ANALYSIS.md#ep-01) · catalogue `1f067a8` · [EP-01](../../../discovery-reference/Updated%20Requirements/catalogue/requirements/EP-01.md)

> Structural: (1) No Slot entity: a 'free' List IS the Slot (id L-reg-date-session, statusKey free). Naming collision is worse than the reviewer noted: every generated empty Slot carries ListState 'DRAFT' and the admin ListDrawer header prints it (ListDrawer.tsx:50), so an empty slot reads 'DRAFT'. UI wording for the lifecycle state needs renaming or Draft Lists need distinct wording ('Being prepared'). If Draft Lists can hold Bookings (OQ-44 recommendation) Cards need a parent that is not an anaesthetist's List. (3) List.statusKey conflates availability (free/unavailable/holiday) with booking class (private/public/preop). OQ-17 and OQ-27 decide the vocabulary; plan US-01.2.1, 2.2, 2.3, 5.3 together after that ruling or with an explicit interim assumption. statusKeyParity test and StatusLegend depend on the six keys.\nVerification changes: EP-01, FT-01.2, FT-01.3, US-01.3.1 moved to Contradicts (assigned Lists with no surgeon/hospital are deliberately built and seeded; displayed status depends on bookings); US-01.3.2 moved Matches to Partial (new/edited Permanent List does not reach the existing canvas, weekend templates silently ignored, no delete); US-01.5.4 moved to Contradicts (un-blocking a booked session writes a new conflict, and no path clears a conflict). Matching screen (US-02.1.2) is the second Draft List entry point. Update-email button after reassignment (OQ-46, US-02.3.3) hooks onto reassignList. One-day dashboard (US-13.1.1) must show Draft Lists. Audit (US-13.5.2) already covers reassignList/setAvailability.\nDemo controls: harness bar has no screen-contextual slot (confirmed in shell map). 'Simulate incoming request' (Draft Lists) and 'Simulate sickness' (Admin day view) need a shared contextual-trigger registry in src/shared modelled on demoClockShortcuts, so the PWA import closure stays pure. Most other items demo through existing UI or the clock.\nDemo script impact (docs/demo-guide/03-demo-script.md): S2 Beat 1 'two half-day Lists' wording becomes Slots; S2 Beat 2 phone-advice booking admits anaesthetist views still show Free (fixed by US-01.2.3/01.3.3, caveat and Expected line change); the seeded Fitzgerald 'Surgeon TBC' List (Tue 21 PM) must change or become a Draft List under US-01.3.1; S2 Beat 3 vacated-slot Unavailable vs catalogue default Available.
