# EP-01 · Schedule canvas, Slots and Lists · gap details

Part of the [gap analysis](../GAP-ANALYSIS.md#ep-01) · catalogue `501b0b8` · [EP-01](../../../discovery-reference/Updated%20Requirements/catalogue/requirements/EP-01.md)

> Core structural gap: Slot and List are ONE record (List with statusKey free/holiday/unavailable/private/public/preop) and List.anaesthetistId is mandatory. Draft Lists (FT-01.6, US-01.6.1 to 01.6.4, US-01.4.3 move-to-office/withdraw, US-01.5.2 unavailable-becomes-Draft per OQ-27) need a nullable anaesthetist or a separate Draft List entity plus a PERSIST_VERSION bump (currently 13). Second wrong seam: availability is a separate master reconciled into Lists (setAvailability), where the catalogue wants one mechanism; and office-booked Free slots keep statusKey 'free' (parked P5), so mobile/web, the admin drawer chip and requestCover treat them as Free while only the admin grid derives 'private'. Fixing P5 (restatus on booking, or List overrides status everywhere and remove displayStatusKeyForList derivation) closes US-01.2.3, FT-01.2 and the Free-reading part of US-01.3.3 together. Surgeon-optional Lists (phone advice, 'Surgeon TBC', EditListSheet clears) contradict FT-01.3 / US-01.3.3 'exactly one surgeon and hospital' (public acute/pre-op need a ruling). Verifier changes: EP-01 Partial to Contradicts and US-01.3.3 Partial to Contradicts (wrong behaviour present); all other grades upheld with evidence added (RequestCoverSheet copy 'notified when someone accepts' contradicts no-acceptance rule; Anaesthetist.active does not gate canvas generation; no start date on Anaesthetist). OQ-64 (logical model) is still Open, so model work should follow a settled reading; Draft List creation and the anaesthetist-move flow can be built independently. Dependencies: US-13.6.3 blacklist master (US-01.4.5, US-01.6.3), US-02.3.3 draft update email (after reassignList), US-06.3.5/US-06.5.4 prepayment re-check on moved Bookings (US-01.4.6), US-13.1.1 one-day dashboard (US-01.6.2), US-01.4.2 availability finder, OQ-65/OQ-43 notification and warning copy. Vocabulary drift: UI says Permanent lists, Card, List statuses; catalogue says recurring bookings, Booking, Slot status. Demo-script beats affected (docs/demo-guide/03-demo-script.md): S1 canvas roll-forward narrative stays valid; S2 beat 2 phone-advice booking on Sharma Tue 21 PM (notes anaesthetist views still show Free; changes when P5 fixed and surgeon becomes required); S2 beat 3 illness-cover reassign stays valid (add Draft List and email offer if built); S2 availability/conflict discovery point changes if unavailability converts Lists to Draft Lists. Anaesthetist cover offer/request (Phase 03 mobile/web) would be replaced by the move flow in US-01.4.3. Prototype scale is 14 anaesthetists vs 85 (narrated, scale test exists), not graded as a gap.
