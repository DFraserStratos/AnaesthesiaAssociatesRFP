## EP-01 · Schedule canvas, Slots and Lists · Contradicts

[EP-01](../../../../requirements-board/requirements/stories/EP-01.md) · [board](http://localhost:5180/#/board?item=EP-01) · status Confirmed · surfaces: domain, store, seed, admin, mobile, web, demo-guide · confidence high

- **Requirement:** Every active anaesthetist has an AM and PM Slot (a box with a status, every new one free) across a rolling four-month window; a List goes into a Slot and holds Bookings; a Draft List is a List with no anaesthetist; reference data held by identity.
- **Prototype today:** Generates 2 List records per anaesthetist per day (14 days back to +4 months). The List record doubles as the Slot, default statusKey 'free', but generator RNG-fills about 22% of weekday slots as private/public/unavailable. Hospitals, surgeons, anaesthetists referenced by id. Status set is a TS union. No Draft List.
- **Missing or wrong:**
  - WRONG: new Slots do not all start free (slot-hash RNG fill, also on rolled days and new anaesthetists)
  - WRONG: Slot status is a hardcoded enum, master view is read-only 'fixed enumerated set'
  - No Draft List (List.anaesthetistId mandatory), no way to produce one from any of the four triggers
  - Recurring booking onto an unavailable Slot is silently dropped, not a Draft List
  - Anaesthetist cannot move a List to the office or a colleague; no blacklist; no notification pool
  - Horizon length is a code constant; Anaesthetist.active never consulted by generation
  - Added anaesthetists do not appear on the Admin day grid (static seed roster)
- **Evidence:** `aa-prototype/src/domain/seed/canvas.ts:105-148`, `aa-prototype/src/domain/types.ts:301-330`, `aa-prototype/src/domain/clock.ts:86-104`, `aa-prototype/src/apps/admin/screens/MasterData.tsx:453-470`, `aa-prototype/src/apps/admin/AdminApp.tsx:124-130`, `searched: draft list\|draftList\|unassigned\|blacklist\|notification pool in src -> only hospital label text 'Unassigned' and DRAFT approval-state comments`
- **Verifier:** corrected from Partial. Re-read the epic body and generator. Epic states its own rule 'every new Slot starts as free' and Slot status 'not a fixed set'; the code RNG-fills and uses an enum, so by the Contradicts-over-Partial rule this is Contradicts. Reviewer's gap list upheld; added active-flag and admin roster points.
