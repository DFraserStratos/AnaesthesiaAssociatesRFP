## US-12.2.2 · GST report · Contradicts

[US-12.2.2](../../../../requirements-board/requirements/stories/US-12.2.2.md) · [board](http://localhost:5180/#/board?item=US-12.2.2) · status Verify (3) · surfaces: web, mobile, domain, store, seed, demo-guide · confidence high

- **Requirement:** Each month the anaesthetist gets a list of the payments AA made to them in the month with the GST component of each (not invoices sent), something to download, email or print so it suits the web app. BCTI treatment still open (OQ-29, OQ-47).
- **Prototype today:** Web Accounts > GST activity: period selector (default from the anaesthetist gstPeriod), rolling window, rows of date received, invoice, payer, amount received, GST component, period totals. Mobile Balances > 'GST this month': receipts this month with GST. Both come from gstActivityFor over billing.receipts.
- **Missing or wrong:**
  - Rows are receipts (r.atISO, grossAmount), not disbursements; billing.disbursements (id, accPayId, amount, atISO, payablesRunId) and case.disbursedAtISO exist and should drive the list (US-10.1.2)
  - Bi-monthly / six-monthly options and the gstPeriod master field contradict a monthly report
  - No download, email or print (searched web apps for print\|download\|mailto\|csv: none)
  - Labels 'Amount received' / 'Payer' / 'No payments received' should read as payments passed to the anaesthetist
  - BCTI link not shown (open in OQ-29, OQ-47; status Verify, so low priority)
- **Demo trigger:** Existing 'Simulate payment and payout' on the Xero pair view (Demo > Xero) records the disbursement that should populate the month's report; add 'Download CSV', 'Print' and 'Email me this report' buttons on the web GST activity tab (CSV/print produce a file or print view of the rows; email shows a sent confirmation toast).
- **Evidence:** `aa-prototype/src/store/selectors.ts:975-1005`, `aa-prototype/src/apps/web/screens/AccountsScreen.tsx:384-470`, `aa-prototype/src/apps/mobile/screens/BalancesScreen.tsx:40-45,113-135`, `aa-prototype/src/domain/types.ts:1361-1367 (Disbursement), :237 (GstPeriod)`
