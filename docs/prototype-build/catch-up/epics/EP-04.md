## EP-04 · Contracts · Contradicts

[EP-04](../../../../requirements-board/requirements/stories/EP-04.md) · [board](http://localhost:5180/#/board?item=EP-04) · status Agreed (4) · surfaces: admin, web, mobile, domain, store, seed, demo-guide · confidence high

- **Requirement:** Every Procedure selects exactly one Contract, which sets pricing and who is billed (holder if it pays AA, else the Booking's payer); no billing route step; dated versions never deleted; staged changes; No contract (RVG) offered first, held by AA.
- **Prototype today:** Procedure has billingRoute (hospital/billableParty/insurer) plus optional governingContractId; route decides the payer; unset contract falls back to the hospital/insurer default Type 1 at billing time; Contracts are single edited-in-place records that can be deleted.
- **Missing or wrong:**
  - Billing route still decides who is billed; contract-holder route bills the holder whatever its kind (seed: surgeon-held Doyle bariatric Contract on the hospital route bills the surgeon, catalogue says the Booking's payer)
  - Contract optional on a Procedure; default Type 1 per hospital/insurer instead of one AA-held No contract (RVG)
  - Contract kinds Type 1/2/3 (catalogue: no kinds, settings only)
  - No holder records, no header+lines, no dated versions, no staging/review/submit
  - Contracts hard-deletable and edited in place
  - No per-Contract editable/prepaid flags, no AA code
  - Picker unfiltered, not holder/context-narrowed
- **Evidence:** `aa-prototype/src/domain/types.ts:367-432`, `aa-prototype/src/domain/types.ts:787,831-832`, `aa-prototype/src/domain/billing/invoiceBuild.ts:114-216`, `aa-prototype/src/store/contractActions.ts:28-45,152-180`, `aa-prototype/src/shared/flows/EditBillingSetupSheet.tsx:175-183`, `aa-prototype/src/domain/seed/contracts.ts:20-70`, `aa-prototype/src/domain/seed/bookings.ts:697-716`
