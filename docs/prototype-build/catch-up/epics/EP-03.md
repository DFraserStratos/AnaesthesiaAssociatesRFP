# EP-03 · Booking and Procedure capture (anaesthetist) · gap details

Part of the [gap analysis](../GAP-ANALYSIS.md#ep-03) · catalogue `60e2d1e` · [EP-03](../../../../requirements-board/requirements/stories/EP-03.md)

> EP-03 holds up as one structural gap: the prototype is still the July model (Procedure = free-text description + one RVG base code; Contract is a stored id set only by the office). Missing structure: source text vs procedure wording, procedure master and two-tab picker, anaesthetist-editable Contract with a filtered list, modifier records with explanations and locked age/included modifiers, Contract-driven price rule (first-party vs third-party vs fixed discount), dated billing lines without rate x time, ASA as an ordinary modifier. Do this as one capture rework (shared BtmCaptureBlock serves mobile, web and admin, so one change lands on all three). Cross-epic dependencies: EP-05 (procedure master, RVG groups, modifier table, US-05.1.x), EP-04 (Contract kinds and list filter, US-04.2.x/US-04.3.2), EP-13 (out-of-range warning routine, US-13.7.1; only prepaymentUnpaid exists), EP-07 (review flag for anaesthetist changes, US-07.2.2), EP-06/08 (prepaid amount), EP-02 (as-received text, US-02.5.7). Verifier corrections: (1) base units are not actually blocked out of range in the UI: the UnitsCard B stepper accepts any value silently while only the range selector clamps and the validator rejects missing/out-of-range baseUnitsSelected, so the real gap is no warning plus a contradictory validator rule; (2) BMI, emergency and awake intubation modifiers exist (OB, ASE, AI1), only ASA is wrongly separated; (3) prePaidByProcedure lives only in domain invoice build, not selectors. Open questions (OQ-99, 101, 95, 96, 89, 103) all land inside the rework. Demo-guide impact: S1 Beat 3, S4 prepayment beat, S5 compliance edits (AS1/AS2 on Chen) and the demo-plausible modifier discussion. Existing triggers (fire-hospital-message, S4 jump, demo clock) cover the automatic parts; no new EP-03 triggers are essential, but seed needs older billed Lists (PERSIST_VERSION bump) for US-03.1.6 and patients in the age bands for US-03.3.8.
