# EP-03 · Booking and Procedure capture (anaesthetist) · gap details

Part of the [gap analysis](../GAP-ANALYSIS.md#ep-03) · catalogue `efe123c` · [EP-03](../../../../requirements-board/requirements/stories/EP-03.md)

> EP-03 capture UI is largely the July build on the old model: billing route plus governing Contract Type 1/2/3, ASA-seeded modifier units, a mandatory override reason on any Contract, the anaesthetist seeing no price on the Booking (the web List table is the exception), and the 'post-op addendum' (labelled 'Add post-op event') as a linked Booking on a new List. Verifier changes: FT-03.3, US-03.3.3 and US-03.6.1 moved from Partial to Contradicts because the prototype asks for times, modifiers or in-range units on fixed-price Contracts and blocks completion on things the catalogue says should not block. The Matches items (FT-03.2, US-03.2.1, US-03.1.4) were re-checked and upheld. Caveat on US-03.2.1: the equal modifier split above 4 units (US-05.3.1) is not implemented, and no UI sets which Procedure is primary. These are for the EP-05 review. The new Contract-on-Procedure model (EP-04 pricing kind, per-Contract override flag, No contract RVG/Fixed fallbacks, default RVG code, step rail, filtered Contract list US-04.3.2, prepaid Contracts non-editable) is a hard prerequisite for FT-03.4, US-03.4.1, US-03.3.9, US-03.3.3, US-03.5.1, US-03.5.2, US-03.3.1 and US-03.6.1, so schedule them after the EP-04 contract phases. Also change the anaesthetist edit window to AUTHORISED in lifecycle.editRefusal, with an office-review flag on anaesthetist changes (US-07.2.2). Events (FT-03.7, US-03.1.10, US-03.7.4) depend on EP-08 additional invoices, credit notes and invoice description (US-08.4.6), EP-05 (US-05.5.2 ACC pre-op) and the EP-07 billing run for next-run bundling. The addendum code (addPostOpAddendum, 'INTERIM until Phase 38b') should be retired. The out-of-range base-units warning depends on the US-13.7.1 warning routine, where only prepaymentUnpaid exists. Procedure-text replacement (US-02.5.7) and invoice description (US-08.4.6) feed US-03.1.9. Demo-guide impact: S1 Beat 3 says the anaesthetist 'sees no running fee' and walks ASA, modifiers and Start/Finish, so US-03.3.10, the ASA seed removal (US-03.3.4) and the Contract-driven form collapse (US-03.3.9) change its script; S2 Beats 2 and 4 are affected by Contract-on-Procedure and the edit window; S4 Beat 2 'post-op addendum' is replaced by events; S4 Beat 1 gains the prepaid amount (US-03.1.8). Bump PERSIST_VERSION when the seed gains pricing kinds, the override flag, default RVG code or events.
