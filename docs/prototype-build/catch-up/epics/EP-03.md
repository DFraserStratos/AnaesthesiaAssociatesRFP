# EP-03 · Booking and Procedure capture (anaesthetist) · gap details

Part of the [gap analysis](../GAP-ANALYSIS.md#ep-03) · catalogue `3d3a18c` · [EP-03](../../../discovery-reference/Updated%20Requirements/catalogue/requirements/EP-03.md)

> Structural: FT-03.7 needs a new Event entity (child of Procedure: own date/time, time or fixed fee, invoiced tick, billable party with same-as flag, source anaesthetist or admin). It replaces the post-op addendum (Booking.bookingType 'postOpAddendum', addendumOfBookingId, addPostOpAddendum, 'Add post-op event' button, 'Stage post-op scenario' trigger in shared/demoTriggers/registry.ts:313 and the DemoControlPanel exceptions walk-through; code comment already says Phase 39 replaces it). The four event items (FT-03.7, US-03.7.1/2/3) are one build, not four. Invoice build/billingRun must learn events: line on a pending Procedure invoice vs separate traceable invoice next run, via the same review step. US-03.7.3 also depends on additional invoices and credit notes (US-08.6.x, OQ-72); Invoice.kind has no credit note. Cross-epic dependencies: US-03.3.1 and US-03.2.3 depend on the master procedure list, default RVG Contracts and procedure-filtered Contract list (US-04.3.1/04.3.2, US-04.4.2, US-05.1.x); base units must move from RvgCode to Contract (unit-range location still open). Cheap partial fix for US-03.3.1 independent of that: unclamp the range stepper, drop the validator range failure and register an out-of-range warning rule in the 15a routine. US-03.5.1 needs a Contract setting for whether anaesthetist adjustment is allowed (US-04.2.2 / US-05.4.1) plus a percent mode on the anaesthetist card. US-03.3.6 depends on the Contract unit rate (US-05.2.6) and open OQ-89; add a line date field regardless; post-care lines may move to events. Matches with no gap: US-03.1.3 (attachments), US-03.3.4 (ASA seed + itemised modifiers; modifier master gaps such as beach-chair/prone and VM1, TTE etc. are US-05.1.5 master data), US-03.6.2 (incomplete Bookings listing). All three re-checked in code, including the Confirmed one. Demo-script impact (docs/demo-guide/03-demo-script.md): S4 Beat 2 post-op addendum (Stage post-op scenario, Add post-op event, new addendum Booking) breaks when addendum is replaced by events. Beats touching RVG code pick or base units (S1 capture, Ellison hip replacement, S3 money beats) change if base units seed from the Contract and range entry is unclamped. Beats showing the Price override card or the rate x time line (Aria hourly contract booking) change with US-03.5.1 and US-03.3.6. S1 List attachment aside is unaffected.
