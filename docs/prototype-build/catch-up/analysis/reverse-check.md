Code is the truth; the old build docs were used only as leads. Catalogue links are relative to this file. Paths are under the repo root (`aa-prototype/src/...`).

This run re-checks the prototype at HEAD `60e2d1e` (code unchanged since Phase 15a, commit `b342a7d`) against the catalogue as it stands on 2026-10-08, including the 5, 6, 7 and 8 October answers and the Contract model rewrite.
